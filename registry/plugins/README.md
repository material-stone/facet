# Facet 플러그인 목록

Facet의 **설정 → 플러그인 → 플러그인 받기**에서 아래 플러그인을 바로 설치할 수 있어요.

## 설치하는 방법

1. 오버레이에서 **설정** 탭을 엽니다.
2. **플러그인 → 플러그인 받기**에서 원하는 플러그인의 **설치**를 누릅니다. 설치하면 바로 켜져요.
3. 대시보드 같은 탭에서 위젯 편집 버튼을 누르고 **위젯 추가**에서 플러그인 위젯을 배치합니다.
4. 지우려면 **플러그인 → 설치된 플러그인**에서 휴지통 버튼을 누릅니다. **삭제**는 기록을 남기고, **데이터까지 삭제**는 기록과 설정도 지워요.

> ⚠️ 플러그인은 Facet과 같은 권한으로 실행됩니다. 믿을 수 있는 플러그인만 설치하세요.

## 플러그인

| 플러그인 | 위젯 | 설명 |
| --- | --- | --- |
| **시계** (`facet.clock`) | 날짜와 시계, 요일, 시계 | 날짜와 현재 시각, 오늘 요일을 보여 줍니다. 요일·시계 위젯은 아날로그·디지털과 스타일을 위젯마다 고를 수 있고, 위치를 9방향으로 맞출 수 있어요. |
| **날씨** (`facet.weather`) | 날씨 | 현재 날씨와 습도를 보여 줍니다. 지역은 플러그인 설정에서 고릅니다(Windows 위치 또는 국내 시·도). |
| **일정** (`facet.schedule`) | 달력·일정, 오늘 일정 | 달력에서 날짜별 일정·할 일·노트를 관리하고, 하루를 시계 모양 원 위에 계획합니다. 오늘 일정 위젯은 다가오는 일정을 보여 줘요. |

## 직접 만들기

플러그인은 `Facet.Plugins`만 참조하는 .NET 10 WPF 클래스 라이브러리입니다. [플러그인 작성 안내](../../docs/plugins/README.md)와 [플러그인 업로드 안내](UPLOAD.md)를 참고하세요. 올린 플러그인은 관리자 검토 후 목록에 공개됩니다.
