# Facet 스킨 목록

Facet의 **설정 → 스킨 → 스킨 받기**에서 아래 스킨을 바로 설치할 수 있어요. 기본 스킨은 Facet에 들어 있습니다.

## 설치하는 방법

1. 오버레이에서 **설정** 탭을 엽니다.
2. **스킨 → 스킨 받기**에서 원하는 스킨의 **설치**를 누릅니다. 설치가 끝나면 바로 적용돼요.
3. 다른 스킨으로 바꾸려면 **스킨 → 사용할 스킨**에서 고릅니다.

## 스킨

| 스킨 | 설명 |
| --- | --- |
| **우주** (`space`) | 행성 사이를 지나는 우주 항해 배경, 은은한 네뷸라와 별, 각진 HUD 위젯. 화면 가운데 조준선은 스킨 옵션에서 끌 수 있어요. |
| **복셀 월드** (`voxel`) | 시장 거리, 물가의 집, 광맥 동굴을 오가는 실시간 3D 복셀 배경. 시간과 날씨에 따라 바뀌고, 배경을 누르면 다음 장면으로 넘어갑니다. 둥근 HUD와 손글씨 느낌의 글꼴을 씁니다. |
| **고양이 방** (`catroom`) | 햇살 드는 방에서 치즈 고양이가 산책하고, 그루밍하고, 도넛 침대에서 낮잠 자고, 방울과 털실로 놀아요. 창밖은 시간과 날씨를 따라 바뀌고, 고양이를 누르면 골골거리고 바닥을 누르면 털실이 떨어집니다. 위젯도 방 안 소품으로 직접 그립니다: 고양이 얼굴 시계, 나무 날씨 팻말, 코르크 보드 일정, 선반 위 기분 토큰, 츄르 튜브 7일 컨디션, 벤치 위 낮잠 고양이 7일 수면, 크림색 탭 막대. 골골송, 방울 소리, 털실 통통, 창문 빗소리 같은 작고 부드러운 효과음은 모두 코드로 합성하며 스킨 설정의 "효과음"으로 끌 수 있습니다. |
| **미드나이트** (`midnight`) | 보랏빛 남색으로 색만 바꾸는 가벼운 스킨. |

## 직접 만들기

스킨은 `skin.json`과 이미지·글꼴 같은 파일로 만듭니다. 만드는 방법과 올리는 방법은 [스킨 업로드 안내](UPLOAD.md)에 있어요. 이 폴더의 스킨들이 예제입니다.
