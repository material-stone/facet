## 설치 / Install

- **설치 프로그램 (권장)**: `Facet-<버전>-setup-x64.exe`를 실행합니다. 관리자 권한이 필요 없습니다.
- **포터블**: `Facet-<버전>-win-x64.zip`을 풀고 `Facet.Launcher.exe`를 실행합니다.
- 위젯은 **설정 → 플러그인 → 플러그인 받기**, 스킨은 **설정 → 스킨 → 스킨 받기**에서 설치합니다. ([플러그인 목록](https://github.com/material-stone/facet/blob/main/registry/plugins/README.md) · [스킨 목록](https://github.com/material-stone/facet/blob/main/registry/skins/README.md))

Run the setup (no admin rights needed) or unzip the portable package. Add widgets under **Settings → Plugins** and skins under **Settings → Skins**.

코드 서명이 없어 Windows SmartScreen 경고가 뜰 수 있습니다. **추가 정보 → 실행**을 누르세요. 파일 해시는 `SHA256SUMS.txt`에 있습니다.
The files are not code-signed yet, so SmartScreen may warn; choose **More info → Run anyway**. Hashes are in `SHA256SUMS.txt`.
