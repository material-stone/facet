## 설치 / Install

- **설치 프로그램 (권장)**: `Facet-<버전>-setup-x64.exe`를 실행합니다. 관리자 권한이 필요 없습니다.
- **포터블**: `Facet-<버전>-win-x64.zip`을 풀고 `Facet.Launcher.exe`를 실행합니다.
- 기능은 앱의 **설정 → 플러그인·스킨 목록**에서 플러그인으로 설치합니다.

Run the setup (no admin rights needed) or unzip the portable package. Add features from **Settings → Plugins & skins**.

코드 서명이 없어 Windows SmartScreen 경고가 뜰 수 있습니다. **추가 정보 → 실행**을 누르세요. 파일 해시는 `SHA256SUMS.txt`에 있습니다.
The files are not code-signed yet, so SmartScreen may warn; choose **More info → Run anyway**. Hashes are in `SHA256SUMS.txt`.
