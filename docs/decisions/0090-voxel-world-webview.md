# 복셀 월드 스킨과 WebView2 배경

2026-11-05: 시장·물가·동굴 세 장소의 실시간 3D 복셀 월드를 스킨으로 추가한다. ADR 0077의 "테마는 데이터이고 코드와 레이아웃을 담지 않는다"는 원칙은 유지한다.

- 렌더러는 WebView2의 WebGL2다. 그림자, 빛 번짐, 비·눈 입자, 수십만 면을 WPF `Viewport3D`로 다시 만드는 비용이 크고, ADR 0086의 "HLSL 없이 Viewport3D" 판단은 행성 수준의 장면에 한정된다. 의존성은 `Microsoft.Web.WebView2` 하나이며 Windows 11에 포함된 런타임을 쓴다.
- 오버레이는 `AllowsTransparency` 레이어드 창이라 HWND 자식을 표시할 수 없다. 월드는 `Design/WorldBackdrop`이 소유한 별도 창에 두고 `SetWindowPos`로 오버레이 바로 아래에 맞춘다. 이 창은 포커스와 입력을 받지 않는다.
- 월드 스킨에서 오버레이는 알파 1의 배경으로 모든 클릭을 받는다. 위젯이 처리하지 않은 왼쪽 클릭은 다음 장소로 넘기며, 전환은 비행 없이 짧은 페이드로 즉시 일어난다.
- 월드 스킨에서는 배경 캡처와 블러, 색조를 쓰지 않는다. 월드가 화면 전체를 덮기 때문이다. 투명도 100%면 월드를 숨긴다.
- 테마 슬롯 `world.scenes`는 `market`, `lakeside`, `cave` 중에서 순서를 고른다. 모르는 id나 중복은 매니페스트 전체를 거부한다. 장면 형태와 움직임은 `Design/World/world.html`의 코드다. 팔레트 슬롯은 필요해질 때 추가한다.
- 페이지는 앱 리소스 하나이고 CSP로 외부 요청을 막으며 다른 주소로의 이동을 취소한다. 메시지는 앱에서 페이지로 `scenes`, `weather`, `visible`, `next`만 보낸다. 시각은 페이지가 로컬 시계로 읽는다.
- 날씨는 기존 `WeatherClient`와 사용자가 고른 지역을 재사용해 표시 중 30분마다 받고, WMO 코드만 `WorldWeather.Key`로 바꿔 넘긴다. 위치 좌표와 기록은 페이지에 전달하지 않는다. 실패하면 하늘을 그대로 둔다.
- 비용 제어: 브라우저는 스킨이 처음 표시될 때 시작하고, 숨김 상태에서는 그리지 않으며, 표시 중에는 30 fps로 제한한다. 내부 해상도 폭은 1920으로 제한한다. 장면은 처음 볼 때 만든다.
- 런타임이 없거나 페이지가 실패하면 월드를 버리고 토큰과 기존 색조만 남긴다. 스킨 때문에 앱이 멈추지 않는다.
- 테마 슬롯 `hudStyle`(`tactical` 기본, `soft`)을 추가하고 `WidgetTheme.IsSoftHud`로 공개한다. 플러그인 계약의 공개 추가다. `soft`는 HUD 위젯의 내용과 처리기를 그대로 두고 둥근 토큰 패널, 앱 글꼴, 머리글 장식 없음, 색 타일 컨디션으로 표현만 바꾼다. 스킨을 고르면 위젯 모양도 함께 바뀌고 다른 스킨은 그대로다.
- 스킨은 HUD 위젯의 레이아웃, 표시 항목, 글꼴, 색을 바꿀 수 있다. 위젯은 `WidgetTheme`로 자기 표현을 고르고, 스킨 글꼴은 `AppFontFamily` 토큰과 `Hud.NumberFont`로 따른다. 컨디션 색은 플러그인이 표현별로 소유한다.
- `Facet.Plugins`의 공개 멤버는 설치된 플러그인이 바인딩하므로 종류를 바꾸지 않고 추가만 한다. `Hud.Mono`를 속성으로 바꿨을 때 음악과 7일 컨디션이 `MissingFieldException`으로 깨졌다.
- 복셀 스킨 글꼴은 본문 Gowun Dodum, 제목과 숫자 Jua다. 둘 다 SIL OFL 1.1이고 원본 라이선스를 함께 배포한다. 다른 스킨은 Pretendard를 유지한다.
- 데이터 폴더는 `%LOCALAPPDATA%/Facet/world-webview`이며 사용자 기록을 담지 않는다.
