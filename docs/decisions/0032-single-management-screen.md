# 관리 화면을 달력 하나로 정리

2026-10-24: 사용자는 다른 캐러셀 항목을 없애고 달력 화면만 남기기를 요청했다. 0017·0028의 세 항목/부분 이웃/순환 드래그 정책을 대체한다.

OverlayTabs의 두 배경 전용 항목을 제거한다. 기존 OverlayCarousel host의 설계 크기 1280×800과 중앙 배치·가용 높이·그림자 여백은 재사용하여 현재 표시 크기를 유지한다. 항목이 두 개 미만이면 BeginDrag는 입력을 소비하거나 마우스를 캡처하지 않고 Rendering 구독도 만들지 않는다. 날짜를 눌러 여는 하루 파이·할 일·노트와 달력 복귀, 자동 저장·포커스·단축키는 그대로 유지한다.

검증은 단일 콘텐츠·이웃 부재·드래그 불가·크기별 중앙 정렬과 기존 날짜/하루 전환·저장·그림자 회귀로 수행한다. 이전 캐러셀 전용 성능 명령은 제거하고 측정 보고서는 당시 세 항목 구성의 역사적 결과로 보관한다. 배경 캡처·Core·저장 형식은 변경하지 않는다.
