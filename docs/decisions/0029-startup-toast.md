# 숨김 시작의 실행 토스트

2026-10-24: 직접 실행·재실행 시 ShowOverlayOnLaunch가 false이면 앱이 실행되었음을 짧게 알린다. true이면 오버레이만 열고 실행 토스트를 표시하지 않는다.

Controller.HandleLaunch에서 시작 출처와 설정을 확인하고 기존 ToastWindow의 startup 모드를 사용한다. 새 프로세스의 일반 실행과 기존 인스턴스에 보낸 재실행 요청이 같은 조건으로 오버레이 또는 실행 토스트를 표시한다. 빠른 재실행은 기존 토스트를 교체한다. --autostart/--tray는 기존 무표시 정책을 보존한다.

ToastWindow는 공통 Panel·Mint·타이포그래피를 사용해 실행 안내만 13 DIP 글씨 한 줄로 표시한다. 단축키·아이콘·버튼은 표시하지 않는다. 내용에 맞춰 창 크기를 정하고 좌우 12 DIP·상하 7 DIP 패딩과 8 DIP 모서리를 사용한다. 최상단·비활성 창이며 주 모니터 WorkingArea 가로 중앙, 작업 표시줄 위에 DPI를 반영한 16 DIP 여백으로 배치한다. 투명도 0에서 1까지 200ms, 완료 후 2초 유지, 1에서 0까지 200ms로 애니메이션하고 닫는다. 마우스를 올리면 자동 종료 타이머를 멈추고, 마우스를 떼면 2초를 새로 센 뒤 페이드아웃한다. 자동 종료·클릭 종료 어느 페이드아웃 중이든 마우스를 다시 올리면 종료 상태를 해제하고 현재 투명도부터 200ms로 복구해 유지한다. 전환 버전으로 이전 애니메이션의 늦은 완료를 무시한다. 클릭은 뒤의 앱으로 통과시키지 않고 소비하며, 마우스가 올라가 있어도 클릭하면 현재 투명도부터 즉시 200ms 페이드아웃한다. 반복 클릭은 종료 애니메이션을 다시 시작하지 않고 페이드인 중 클릭해도 유지 타이머를 시작하지 않는다. 닫힐 때 타이머와 애니메이션을 정리한다.

기존 일정 알림과 Controller의 토스트 슬롯을 공유해 표시 중 일정은 다음 Tick에 처리하고 종료 시 함께 정리한다. 실행 안내는 알림 이력에 저장하지 않는다. 일정 알림의 열기·닫기 버튼과 20초 수명은 유지한다. Core·저장 스키마와 오버레이의 사용자 지정 페이드 설정은 변경하지 않는다.

합성 Launcher 검사로 설정 off의 직접 실행·기존 인스턴스 재실행 토스트 표시, 설정 on의 두 경로 토스트 무표시, 주 모니터 작업 영역·native 비활성·클릭 수신 속성, 완전 표시·자동 닫힘·약 2.4초 수명, 자동 시작·자동 재실행의 무표시를 확인한다. WPF 마우스 진입·이탈 이벤트로 2.4초 hover 유지와 이탈 후 새 2초 대기를 확인한다. 자동·클릭 페이드아웃 양쪽의 중간 투명도에서 재진입해 투명도가 튀지 않고 복구된 뒤 2.4초 이상 유지되는지 확인한다. 콘텐츠에서 발생시킨 WPF 마우스 이벤트로 hover 중 클릭 후 중간 투명도·약 200ms 종료, 반복 클릭 시 종료 진행, 전경 포커스와 앱 화면 숨김 유지를 확인한다. 실제 포인터를 이동하거나 OS 마우스 입력을 보내지는 않는다.
