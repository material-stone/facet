# 0055 — 수면 탭의 기록 구간과 평균

2026-10-25: 0052에서 대시보드에만 적용했던 기록 구간 대체 값을 수면 탭의 날짜별 수면 시간과 평균에도 적용한다. 기존 Desktop/SleepDurationChart.Minutes를 공통 선택 함수로 재사용한다. 입면·각성 분이 모두 있으면 기존 추정 수면을, 어느 하나라도 비어 있으면 잠 시도~기상 전체 구간을 사용하며 한쪽 분만 빼거나 원자료의 미입력을 0으로 채우지 않는다.

OverlaySleepView의 날짜별 표시는 보정된 값과 대체 값 모두 ‘수면 시간’으로 통일하고 기존 공통 시간 형식을 사용한다. 평균은 같은 선택 함수가 반환한 최근 7일의 값만 포함하며 평균 옆의 ‘몇 일 기준’ 문구는 표시하지 않는다. 두 시각이 부족하거나 계산 불가능한 값은 제외하고 실제 0은 포함한다. 평균의 기존 분 단위 반올림과 0인 단위 생략은 유지한다.

대시보드도 수면량 그래프 아래에 최근 7일의 평균 수면 시간을 표시하며 ‘몇 일 기준’ 일수 문구는 표시하지 않는다. 같은 Minutes 선택 함수와 반올림·시간 형식을 사용하며 표시 가능한 값이 없으면 0시간 대신 —를 표시한다. 기존 날짜 변경·기록 저장/삭제 갱신 경계에서 평균을 함께 갱신하고 배경은 투명하게 유지한다.

Core 모델·EstimatedSleepMinutes·저장 schema·날짜 키·외부 전송 경계는 변경하지 않는다. 이 결정은 0052의 ‘수면 탭 평균을 변경하지 않는다’ 정책을 대체한다.

검증은 합성 기록의 두 시각만 저장한 직후 일별/평균 반영, 추정 수면과 대체 값 혼합, 한쪽 분 입력·자정/24시간·실제 0 포함·시각 결측 제외·표본 수·반올림·원자료 보존과 화면 밖 렌더를 포함한다. 기본 검사와 Release 배포를 실행하며 architecture 명령은 null이므로 기존 Desktop→Core 경계를 소스에서 점검한다.
