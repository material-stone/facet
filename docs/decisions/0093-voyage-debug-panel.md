# 우주 항해 디버그 패널

2026-11-06: 영상 촬영에서 오버레이를 열 때 행성이 이미 가까이 있도록, 우주 항해 스킨의 F8 디버그에 작은 패널을 둔다.

- **행성 생성**은 하늘의 행성을 모두 지우고 새 행성 하나를 페이드 없이 슬라이더가 정한 지점에 놓는다. 가로·세로는 화면 가장자리까지의 비율(-100~100%, 기본 +50%, 0%), 거리는 행성 크기(extent)의 2~60배(기본 12배)다. 슬라이더는 다음 생성부터 적용한다.
- 화면 중앙을 겨눠도 축 거리를 extent의 1.2배 이상으로 밀어내 VoyagePlan의 충돌 불가 보장을 유지한다. 그래서 가까운 거리에서 중앙 부근을 고르면 요청보다 바깥쪽에 나타난다.
- **빨리감기 x1~x10**은 행성 비행과 다음 행성 대기 시간만 빠르게 하며 스캔 시간은 그대로다.
- 오버레이를 숨기면 비행이 멈추므로 맞춰 둔 위치는 다시 열 때 유지된다.
- 저장하지 않는다. 앱을 재시작하거나 스킨을 바꾸면 사라진다. 패널을 닫아도(F8) 빨리감기 배율은 유지되므로 촬영 전에 확인한다.
