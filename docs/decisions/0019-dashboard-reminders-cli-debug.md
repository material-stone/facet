# 대시보드 알림 카드·로컬 CLI·영역 디버그

2026-10-24: 위치를 한국어로 표시하고 날씨 행의 출처·IP 기준 문구를 제거한다. 습도는 기존 벡터 아이콘 체계에 추가한 물방울 + 퍼센트로 표시한다. 한국 지명은 로컬 표로 변환하고 미지원 지명은 한국어 지역/국가 또는 현재 위치로 표시하여 외부 위치 제공자를 추가하지 않는다. 데이터 출처와 사용 조건은 기존 날씨 문서에 유지한다.

날짜·날씨 행 아래 32 간격을 두고 오늘 주요 일정·알림을 둥근 사각 카드로 가로 나열한다. 사용자 등록 일정·알림, 기존 Scheduler의 오늘 알림, 오늘의 미완료 날짜 할 일을 시간순으로 표시한다. 이미 15분 넘게 지난 기본 시간 알림은 제외하되 기상 기록 미작성 안내와 사용자 등록 일정은 유지한다. 내용이 많으면 가로 스크롤하고 등록되지 않은 샘플 일정을 실제 항목처럼 만들지 않는다. 가로 스크롤은 테마 색의 얇은 막대와 마우스 휠을 지원한다.

Core/UserReminders는 AppData v2의 선택 필드 Reminders와 명령 DTO를 소유한다. 알림에는 Guid ID, 호출자가 지정하는 중복 방지 Key, Title/Body, offset을 포함한 At, schedule/reminder Kind, 완료·취소·전달 시각이 있다. 같은 Key와 같은 내용의 add는 기존 항목을 반환하고, 내용이 다르면 충돌로 거절한다. 완료·취소한 항목은 재전달하지 않는다. 기존 Core 모델·Scheduler·저장 기록은 대체하지 않는다.

Desktop은 기존 Controller의 5초 Tick으로 사용자 알림을 확인한다. 알림 전 저장 성공을 확인하고 전달 상태를 보존한다. 전역 알림 끄기·전체 화면 생략·개인 내용 숨김은 기존 정책을 따른다. 열린 토스트가 있으면 다음 항목을 기다리게 하여 즉시 서로 덮지 않는다. 앱이 종료된 동안은 알림을 실행하지 못하며 재실행 후 지나간 미전달 항목을 확인한다.

AI Agent 인터페이스는 CLI + 로컬 Named Pipe를 선택한다. 별도 HTTP 포트나 MCP 서버 없이 일반 shell을 쓸 수 있는 Agent가 JSON 응답과 exit code를 처리할 수 있다. `Facet.Cli.exe add/list/complete/cancel`은 앱의 Pipe로만 명령을 보내며 암호화 기록 파일을 직접 쓰지 않는다. --start는 고정 실행기를 --tray로 시작할 수 있다. Named Pipe는 CurrentUserOnly, root별 이름, 버전·길이 제한·시간 제한을 적용하고 Desktop UI Dispatcher가 변경을 직렬 처리한다. 저장 실패 시 rollback하고 성공 응답을 보내지 않는다. 추후 MCP가 필요하면 이 명령 경계에 얇은 어댑터를 추가할 수 있다.

F8은 오버레이 내부에서 디버그 모드를 토글한다. hover한 가장 안쪽 FrameworkElement에 hit-test 없는 Adorner 테두리와 이름·크기를 그린다. 변환된 실제 영역을 사용하여 Viewbox 축소에도 맞춘다. 끄면 장식을 제거하며 padding·border·마우스 동작·저장 상태를 바꾸지 않는다.

검증은 순수 모델의 중복 방지·잘못된 입력 무변경·완료/취소/전달·날짜별 투영, 합성 저장소의 암호화 재읽기·실제 CLI/Pipe 왕복·오류 JSON·미실행 앱 동작, 화면 밖 F8 명령/hover 영역 렌더·카드 배치·습도 아이콘·한글 위치로 수행한다.
