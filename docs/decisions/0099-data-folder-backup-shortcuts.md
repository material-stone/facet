# 0099 — Facet 데이터 폴더, 백업·복원, 단축키 설정, 순정 화면 정리

2026-11-14: 공개 배포에 맞춰 사용자 요청으로 다음을 바꾼다.

- **데이터 폴더:** 기본 기록 폴더를 `%LOCALAPPDATA%\MaterialStone\Facet`으로 바꾼다. `LaunchProtocol.DataRoot`는 새 폴더가 없고 옛 `DailyDock` 폴더만 있으면 옛 폴더를 쓴다. 앱은 시작할 때(`--data-dir`·검사 실행 제외) 옛 폴더를 쓰는 인스턴스가 없을 때만 `MoveRenamedRoot`로 한 번 옮긴다. 옮기지 못하면 옛 폴더를 계속 쓴다. AppUserModelID·Run 값·IPC 이름 접두사는 0089대로 유지한다.
- **백업·복원:** 설정 → 데이터에서 기록 폴더를 zip으로 백업한다(`문서\Facet 백업`, `backups`·점으로 시작하는 폴더·`.tmp` 제외, 사용 중인 파일은 건너뛰고 개수를 알린다). 복원은 zip을 검사해(`records.dat` 필수, 폴더 밖 경로 거부) 기록 폴더 옆 `.restore`에 풀고, 다음 시작 때 인스턴스 mutex를 잡은 뒤 지금 폴더를 `.before-restore-<시각>`으로 남기고 바꾼다. 기록은 DPAPI로 암호화되어 같은 Windows 계정에서만 복원된다. 앱이나 설치본을 지워도 기록 폴더는 지우지 않는다.
- **단축키:** 빠른 실행과 종료 단축키를 `Settings.QuickLaunchHotkey`, `Settings.ExitHotkey`로 옮기고 설정 → 단축키에서 바꾼다. 세 키는 서로 달라야 하고, 등록에 실패하면 이전 키를 되살린다. 검사는 고정 키를 넘겨 실제 키를 건드리지 않는다. [0034](0034-launcher-reserved-commands.md)의 고정 예약 키를 대체한다.
- **빠른 실행:** 지금은 PATH 프로그램 실행만 보인다. 도움말, `@` 경로, `@@` alias, `?` 웹 검색은 `QuickLaunchCatalog.Extras` 뒤에 남겨 두고 설정의 검색 엔진·alias 행도 숨긴다. 플러그인이 등록한 런처 모드는 그대로다.
- **숨긴 설정:** 블러 강도 행과 알림 그룹(CLI·에이전트로 등록하는 사용자 알림의 표시, 전체 화면 중 숨김, 화면 공유 모드)을 화면에서 뺀다. 저장된 값과 동작은 그대로다.
