# ADR 0106: 시스템 모니터 플러그인

2026-11-16: 영상용 "관제 화면"에 실시간으로 움직이는 위젯이 필요하다는 요청에 따라 `impls/Facet.SystemMonitorPlugin`(`facet.sysmon`)을 추가한다.

## 결정

- **위젯 하나:** `monitor`가 CPU·GPU·메모리 링 게이지와 네트워크 수신·송신 그래프를 고정 360×200 면에 그리고, 타일 크기에 맞춰 비율을 유지한 채 늘어난다. 색은 스킨 토큰(`Mint`, `Ink`, `Muted`, `Danger`)과 `Hud.NumberFont`만 쓴다. 여러 탭과 한 탭에 여러 번 배치할 수 있다.
- **측정:** 플러그인 하나에 `SystemSampler` 하나를 두고, 보이는 위젯이 구독하는 동안만 스레드 풀에서 1초마다 읽는다. CPU는 `GetSystemTimes`, 메모리는 `GlobalMemoryStatusEx`, GPU는 PDH `\GPU Engine(*engtype_3D)\Utilization Percentage`의 합(작업 관리자와 같은 방식), 네트워크는 켜진 비루프백 어댑터의 바이트 수다. 외부 패키지는 쓰지 않는다. GPU 카운터가 없으면 게이지를 "—"로 표시한다.
- **움직임:** 값은 감쇠가 약한 스프링으로 따라가 조금 넘쳤다가 자리 잡는다. 90% 이상이 되면 경고색으로 바뀌고 퍼지는 링·숫자 확대·흔들림을 한 번 보이며, 85% 아래로 내려가야 풀린다. 최근 최고값 표시는 2초 머문 뒤 내려온다. 보일 때마다 트랙이 돌며 켜지고 게이지가 차례로 차오른다. 그래프는 다음 측정까지 옆으로 흘러간다. 애니메이션은 `CompositionTarget.Rendering`으로 보이는 동안만 돈다.

## 대가

- 온도는 표시하지 않는다. Windows에서 관리자 권한이나 제조사 드라이버 없이 믿을 만한 값을 얻을 수 없다.
- 위젯이 보이는 동안 매 프레임 다시 그린다. 작은 면이라 비용은 작지만 오버레이를 숨기면 측정과 그리기를 모두 멈춘다.
- GPU 값은 3D 엔진만 합산하므로 영상 인코딩·연산만 쓰는 작업은 낮게 보일 수 있다.
