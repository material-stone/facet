# 날짜별 실행 계획

2026-10-15: 기존 계획을 앱에서 실천하고 기록하도록 요청받았다. 오늘을 1일차로 최초 한 번 초기화한다. Core의 고정 계획 템플릿에서 56일 수면/30일 게임 일정을 생성하고 별도 실행 결과를 저장한다. 이전 날짜의 기록과 메모를 보존하며 재시작 시 중복 초기화하지 않는다.

AppData v2는 v1 읽기를 지원한다. Plan에는 시작일, 선택한 주력, 날짜+항목 ID별 상태/메모/갱신 시각을 저장한다. 계획은 의료 처방을 하지 않고 게임 공개를 강제하지 않는다. 수면 기록 연결은 표시상 완료의 근거를 설명하며 사용자 실행 기록과 구분한다. 게임 항목을 작업으로 가져올 때 SourcePlanKey로 중복 생성을 방지한다.

오늘 탭을 첫 화면으로 추가하되 기존 수면/제작 단축키 의미를 유지한다. 관리 화면의 기존 편집 탭 인덱스는 논리 인덱스(수면0/제작1/설정2)로 유지하고 실제 탭 인덱스에서 1을 뺀다. 상태창과 트레이에서 오늘 계획을 열 수 있다. 새 알림을 여러 개 추가하지 않고 기존 알림에서 오늘 실천 항목으로 연결한다.
