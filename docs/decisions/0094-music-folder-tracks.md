# 음악 폴더의 파일을 재생 목록에 추가

2026-11-06: 음악 플레이어의 곡 추가 창에서 YouTube URL과 함께 음악 폴더의 파일을 고를 수 있게 한다.

- 폴더는 `<data>/plugin-data/<플러그인 id>/Music`이다. 플러그인 설치 폴더는 교체될 수 있으므로 쓰지 않는다. 창의 **폴더 열기**로 열며, 창이 열려 있는 동안 2초마다 목록을 다시 읽는다.
- 트랙 ID는 `local:<파일 이름>`이다. 경로 없이 이름만 저장하므로 폴더 밖을 가리킬 수 없고, 링크와 허용하지 않은 확장자는 제외한다.
- Ogg는 Windows MediaPlayer가 추가 코덱 없이 열지 못해 받지 않는다.
- 앱은 이 폴더의 파일을 읽기만 한다. 재생 목록에서 삭제해도 파일은 지우지 않는다(YouTube 캐시 음원은 지금처럼 삭제).
- 재생 목록 JSON은 그대로이며 `VideoId`에 로컬 ID도 담는다. 이전 버전 플러그인은 로컬 곡이 있는 목록을 읽지 못한다.
