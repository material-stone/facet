# 중앙 대시보드 고정과 작은 음악 플로팅 패널

2026-10-27: 아래 중앙 고정·232 폭 리모컨은 유지하며 임베드 영상·숨김 정지는 [0063](0063-browser-music-lifetime-and-indicator.md)의 일반 브라우저 재생과 작업표시줄 위 표시로 교체했다.

2026-10-26: 0061의 대시보드·음악을 하나의 중앙 Grid에 묶는 배치를 교체한다. 원래 DashboardViewport와 최대 폭800 Viewbox의 중심·상하 여백·화면 맞춤은 음악 상태와 독립적으로 유지한다. 양옆 화면 공간을 사용하는 별도 Canvas에 오른쪽 음악 카드만 배치하며 대시보드 오른쪽 실제 표시 경계+24 DIP에 고정한다. 음악 추가·목록 열기·재생은 중앙 대시보드의 측정에 참여하지 않는다.

카드는232 DIP로 줄이고 장식 헤더·설명·빈 영상 자리·이전/다음 버튼을 제거한다. 제목, 재생/일시 정지, 탐색 바, 반복 아이콘, 접는 목록과 URL 추가·삭제를 유지한다. 재생을 요청한 뒤에만206×200 영상이 나타나고, 목록은 기본 접힘·내부 스크롤을 사용한다. 공식 YouTube의 최소200×200 및 영상/오디오 분리·숨긴 플레이어 재생 제한을 따른다. 극소 화면에서는 오른쪽 음악 버튼으로 카드를 겹쳐 열며 중앙 콘텐츠를 밀거나 축소하지 않는다. 카드 외부 높이 스크롤은 작은 화면의 최후 fallback이다.

저장·검증·재생 backend와 기존 목록/반복은0061과 동일하다. 대시보드가 음악을 추가하기 전과 같은 중심·표시 폭·높이를 유지하는지, 목록 열기·재생 상태 전환에도 위치가 바뀌지 않는지 화면 밖 렌더로 검사한다.
