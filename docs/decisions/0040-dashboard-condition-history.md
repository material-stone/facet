# 0040 — 개인 컨디션과 최근 7일 기록

현재 클릭 완료·즉시 저장·단일 시각 선택은 [0046](0046-condition-autosave-and-time-picker.md)이 후속 정책이다.

선택 시각부터 이어지는 개인 컨디션을 대시보드에서 기록한다. 종류는 좋음·괜찮음·피곤함·졸림·아픔·스트레스이며 진단이나 자동 추정은 하지 않는다.

Core/ConditionTracking이 종류 검증, 시각 순서와 구간 투영을 소유한다. AppData schemaVersion 2에 선택 목록 Conditions를 추가한다. 누락 시 빈 목록이며 기존 DPAPI Store와 Controller.Commit으로만 저장한다. 저장 실패 시 기존 상태를 유지한다. 컨디션 기록은 AI·날씨·CLI로 전송하지 않는다.

Desktop/DashboardConditions가 생성 PNG의 검증·로드, 현재 상태 선택 목록, 하나의 연속 게이지를 소유한다. 최근 7일은 로컬 날짜의 6일 전 00시부터 내일 00시까지다. 범위 이전의 마지막 상태는 이어지고, 최초 기록 전과 미래 구간은 투명하다. 기록은 자동 만료하지 않고 다음 선택까지 유지한다. 화면 타이머는 표시만 갱신하고 기록을 만들지 않는다.

800 DIP 행에서 시계·날씨·컨디션의 실제 내용 사이 두 간격을 같은 가변 폭으로 배치하며 컨디션은 오른쪽에 정렬한다. 드롭다운은 아이콘 아래에 연다. 자산은 feature module의 pack URI loader를 통해서만 읽는다.

후속 편집: 각 투영 구간은 잘리기 전 원본 RecordedAt을 보존한다. 구간 클릭은 별도의 기록 편집 팝업에서 날짜·시각(초)·종류를 확인/수정하거나 삭제한다. Core.Update/Delete는 원본 시각과 종류가 여전히 일치하는지 확인하고 미래·중복 시각을 거절한 뒤 원자적으로 변경한다. 삭제 후 이전 상태는 다음 기록까지 이어지며 최초 기록 삭제 전에는 투명해진다. 저장 실패는 초안을 유지한다. schema와 기존 기록은 그대로 읽는다.

대시보드의 컨디션 아이콘은 76 DIP로 확대하고 제목을 없앤다. 아이콘·선택 목록·게이지는 Focusable=false/Tab 탐색 제외이며 자동 Focus를 호출하지 않는다. 별도 기록 편집 팝업의 날짜·시각 입력만 편집을 위해 포커스를 허용한다.
