# 0007 — 앱 내부 Codex Agent와 아이콘 중심 화면

2026-10-17: 복사/붙여넣기 방식 대신 앱에서 현재 진행 상황을 읽는 Agent 연결과 텍스트를 줄인 아이콘 UI를 요청받았다. 0006의 수동 전달 방식을 대체한다.

이미 설치·로그인된 Codex CLI의 비대화식 실행을 Desktop/CodexRoadmapAgent가 소유한다. 인증 파일을 직접 읽거나 토큰을 앱에 저장하지 않는다. 표준입력에는 활성 제작 작업과 게임 분류 실천 기록만 보낸다. 프로젝트 소스/건강 기록 파일을 읽는 도구를 제공하지 않도록 개인 설정·플러그인·앱·shell·브라우저·컴퓨터 도구를 비활성화하고 read-only/ephemeral 실행을 사용한다. 임시 작업 디렉터리는 앱 저장소의 별도 하위 경로이며 요청문은 파일에 쓰지 않는다. 구조화 결과 파일은 검증 후 정리한다. 실행 중 취소/시간 제한/로그인·네트워크 오류를 표시한다.

Core/RoadmapAgentPlan은 제작 스냅샷, 구조화 결과, 계획 필드 변경과 충돌 검사를 담당한다. 사용자는 새 작업과 기존 작업의 수정 차이를 보고 개별 선택 적용한다. 기존 단계·증거·보관·집중·SourcePlanKey는 AI가 수정하지 않는다. 분석 이후 제작 정보가 바뀌면 다시 분석하도록 안내한다. AppData v2에 선택적 RoadmapGoal 문자열을 추가하며 기존 기록은 그대로 읽는다.

화면은 Desktop/Design/Icon의 벡터 아이콘을 사용한다. 주요 기능은 아이콘+짧은 이름, 반복 설명은 키보드 접근 가능한 도움말 아이콘과 펼침 영역으로 이동한다. 상태는 색·아이콘·텍스트를 함께 사용한다. 긴 사용자 기록은 유지한다.

검증: Core의 범위 제한·선택 적용·일괄 검증·충돌·중복 방지, CLI 실행 취소/실패/실제 구조화 응답, 격리 데이터의 모든 탭과 좁은 화면 렌더, 기존 native test와 Release 배포.
