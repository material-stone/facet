# ADR 0107: 월드 페이지에 클릭 위치 전달, 고양이 방 스킨

2026-11-16: 고양이 방 스킨(`registry/skins/catroom`)을 추가한다. 배경 속 고양이·털실·방울을 누를 수 있도록 [0091](0091-world-page-in-skin.md)의 클릭 전달에 위치를 더한다.

## 결정

- **클릭 위치:** 오버레이가 빈 곳 왼쪽 클릭을 넘길 때 `{ next: true, x, y }`를 보낸다. `x`, `y`는 오버레이 창 기준 0~1 비율이고 소수 넷째 자리로 자른다. 좌표 외의 사용자 정보는 보내지 않는다. 위치를 쓰지 않는 페이지(복셀 월드)는 `next`만 보고 다음 장면으로 넘어가므로 그대로 동작한다.
- **고양이 방:** 월드 페이지 하나(`world.html`)가 방, 창밖, 날씨, 고양이 행동을 캔버스로 그린다. 날씨는 앱이 넘기는 상태 이름만 쓰고, 밤은 페이지가 로컬 시계로 정한다. 클릭 위치로 고양이 쓰다듬기, 털실 떨어뜨리기, 방울 부르기를 한다. 위젯은 기존 소프트 HUD(`hudStyle: soft`)에 크림·갈색 토큰과 복셀 스킨과 같은 글꼴을 쓴다.
- **범위 밖:** 고양이 모양 전용 위젯(고양이 얼굴 시계, 코르크 보드 등)은 플러그인 C# 코드라 이번에 넣지 않는다. 포인터 이동(호버)은 페이지에 넘기지 않는다.

## 결과

- 월드 페이지는 클릭이 어디서 났는지 알 수 있다. 위치는 이미 화면에 보이는 정보라 새 개인정보를 넘기지 않는다.
- 월드 페이지가 있는 스킨이라 [0091](0091-world-page-in-skin.md)대로 자동 공개하지 않고 pull request 병합으로 승인한다.
