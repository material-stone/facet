# 주 모니터 오버레이와 포커스 이탈 숨김

2026-10-24: 사용자는 현재 포커스된 화면 대신 주화면에서만 오버레이를 표시하고 포커스를 잃으면 숨기기를 요청했다. 0009의 전경 모니터 선택을 대체한다.

Desktop/Native.CoverScreen은 OverlayWindow에 대해 Windows의 PrimaryScreen 전체 Bounds를 사용한다. 일반 오버레이와 빠른 실행, 재실행·단축키·트레이 열기 및 화면 구성 변경에 같은 정책을 적용한다. native 픽셀과 작업 표시줄 포함 크기는 보존한다. 다른 창의 배치 정책은 유지한다.

OverlayWindow의 Deactivated는 두 모드 모두 기존 저장·페이드 숨김 경로를 사용하며 이전 앱으로 포커스를 복원하지 않는다. 내부 입력 컨트롤 사이의 포커스 이동과 일반 오버레이의 배경 클릭은 닫지 않는다. 저장 실패 시 초안과 기존 표시 요청을 보존한다. 자체 배경 스냅샷을 위한 일시적 Hide는 사용자 포커스 이탈로 처리하지 않는다.

0025의 캡처 도구 예외는 유지한다. 캡처 도구가 보이면 Topmost를 양보하고 포커스 이탈로 닫지 않는다. 캡처 도구가 사라진 뒤 Topmost 복구는 포커스를 빼앗지 않는다. Core와 저장 스키마는 변경하지 않는다.

화면 밖 검사는 두 모드의 비활성화·내부 클릭·캡처 도구 예외를 확인한다. 별도 --overlay-focus 검사는 합성 창으로 주 모니터 Bounds, 다른 모니터에서 열기(다중 모니터가 있을 때), 두 모드의 0ms/페이드 숨김과 새 포커스 보존을 확인한다. 화면 캡처와 전역 키 입력은 사용하지 않는다.
