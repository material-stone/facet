# 0047 — 런처 Codex 채팅과 앱 공유 IPC

2026-10-25: 오버레이 설정의 Codex 연결과 런처 `" ` 채팅을 추가한다. Claude 연결은 이번 범위에서 제외한다.

Desktop/AgentChat은 설치된 Codex의 bundled MCP를 실행하고 현재 사용자 앱 파이프를 발견한다. 연결 기준 채팅 ID만 암호화 설정에 보관하며 인증 토큰·고정 파이프 주소는 저장하지 않는다. 연결 확인은 프로젝트/모델 조회와 IPC 핸드셰이크까지 수행한다. 모델 조회용 App Server는 추론 없이 종료한다.

Codex 앱이 프로젝트 또는 projectless 채팅을 생성하고 대화 원본을 소유한다. 준비용 도구 없는 안내 turn이 끝난 뒤 공유 IPC owner에게 세션별 model/effort/serviceTier를 전달하고 사용자 요청을 시작한다. Fast는 조회된 서비스 등급만 사용한다. owner나 프로토콜을 확인하지 못하면 사용자 요청을 전송하지 않는다. 전송 결과가 불명확하면 자동 재전송하지 않고 Codex에서 확인하도록 안내한다.

대상 채팅 snapshot/Immer patch로 답변·상태를 표시한다. 새 연결은 새 client ID를 받고 다른 클라이언트의 권한 결정을 대신하지 않는다. 승인은 Codex 앱에서 처리한다. 오버레이 숨김은 구독·작업을 취소하지 않으며 명시적 중지만 interrupt한다. 종료 시 follower·자식 MCP/조회 프로세스를 정리하되 Codex 앱은 종료하지 않는다.

입력 중심을 유지하며 `"`에서 왼쪽 위 에이전트, 왼쪽 아래 프로젝트, 오른쪽 아래 모델/effort 버튼을 표시한다. 목록/조절 창은 입력을 가리지 않는 Canvas 레이어에서 열며 바깥 클릭은 레이어만 닫고 뒤로 전달하지 않는다. 모델 선택 후 조절 창으로 돌아온다. 사용할 에이전트가 없으면 안내만 표시한다.

Core의 선택 필드와 AgentChatReferences에는 ID/짧은 제목/호스트/프로젝트/생성 시각만 보관한다. 답변·요청 전문·파이프 주소는 앱 기록에 저장하지 않는다. 최근 세션 참조는 최대 40개이며 목록에서 오래된 참조를 제외해도 Codex 원본을 삭제하지 않는다. 내부 IPC 변경·연결 끊김은 인라인 오류와 재연결로 처리한다. 일반 채팅도 Codex의 projectless 생성 경로를 사용한다. 재조회한 답변의 도구별 출력 제한은 20,000자이며 전체 원본은 Codex에서 연다.

검증: 합성 framing·요청 경계·patch·입력/설정/암호화 왕복·오프스크린 UI와 기존 native checks. 실제 Codex 실행 검사는 명시적 옵션으로만 수행하고 임시 채팅을 정리한다.
