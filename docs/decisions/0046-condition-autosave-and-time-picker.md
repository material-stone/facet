# 0046 — 컨디션 클릭 완료와 즉시 저장·단일 시각 선택

기존 기록 팝업을 MouseDown에 열면 StaysOpen=false의 Popup이 같은 클릭의 MouseUp을 바깥 입력으로 받아 닫았다. 게이지는 누른 원본 기록과 좌표를 보관하고 마우스를 캡처한다. 같은 구간에서 정상적으로 놓은 경우 캡처를 해제한 뒤 팝업을 연다. 바깥 놓기·드래그·캡처 이탈은 열지 않는다. 실제 눌림/놓임과 팝업 유지 검증을 별도 native 입력 검사로 추가한다.

ConditionRecordEditor는 종류·시각 선택 즉시 Controller.Commit으로 저장하고 성공 시 원본 시각/종류를 새 값으로 갱신한다. 성공은 게이지를 갱신하되 팝업을 닫지 않는다. 실패는 마지막 저장과 초안을 보존하고 인라인 오류·재시도를 제공한다. 삭제 성공만 팝업을 닫으며 삭제 버튼은 오른쪽 끝에 둔다. 저장·닫기 버튼은 제거하고 Esc·바깥 클릭으로 닫는다.

ConditionDateTimePicker는 기존 ScheduleDateCalendar를 재사용하는 단일 날짜·시/분/초 선택창이다. 시작·끝 범위와 30분 제한은 갖지 않는다. 하나의 기록 시각 버튼 아래 별도 Popup으로 열고 선택 즉시 자동 저장한다. 원본의 소수 초는 보존하며 미래·중복·오래된 원본 검증은 기존 Core.Update가 수행한다. 중첩 선택창은 부모 팝업의 마우스 캡처와 독립적으로 닫히고 Esc는 가장 안쪽부터 닫는다. schema와 외부 전송 경계는 변경하지 않는다.
