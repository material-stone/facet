# 0100 — 다크·라이트 내장 스킨과 스킨 패키지

2026-11-14: 순정 앱은 다크(기존 기본 토큰)와 라이트(`Design/Skins/Light.xaml`) 두 스킨만 내장한다. 우주·복셀 월드·미드나이트는 앱 코드가 아닌 스킨 패키지로 옮겨 `registry/skins/<id>/`에 둔다. 기존에 고른 스킨이 패키지 설치 뒤 그대로 이어지도록 ID(`space`, `voxel`, `midnight`)는 유지한다. 설치 전에는 다크로 보인다.

## 스킨 데이터와 적용 방식

- 스킨은 `skin.json` 하나와 그 폴더의 자산이다. `colors`는 정해진 토큰의 hex 값, `theme`은 앱이 소유한 시각 효과 슬롯을 켜고 조정하는 값이다. 행성 항해(`voyage`), 네뷸라·별(`nebulaSpeed`, `nebulaBrightness`, `stars`), HUD 위젯(`hudWidgets`, `hudStyle`), 패널 모양, 옵션은 앱의 엔진을 쓰고 스킨은 값만 준다. 3D 월드는 [0091](0091-world-page-in-skin.md)대로 스킨의 HTML 페이지를 잠긴 WebView2에서 띄운다. 글꼴은 스킨 폴더의 파일이다.
- 그래서 코드가 필요한 효과도 스킨은 데이터로 남는다. 새 효과는 앱에 슬롯을 더하는 결정으로 다룬다.
- 복셀 월드가 쓰던 Gowun Dodum·Jua 글꼴과 월드 페이지는 앱에서 빠져 복셀 스킨 패키지에 들어간다.
- `Skins.SharedFolders`는 데이터 폴더 다음에 읽는 추가 패키지 폴더다. 검사는 `registry/skins`를 출력 폴더로 복사해 여기에 넣는다.

## 설정 화면

- 설정 탭은 스킨(사용할 스킨, 스킨 옵션, 스킨 받기), 오버레이(투명도, 배경색, 나타나고 사라지는 시간), 플러그인(설치된 플러그인, 플러그인 받기)을 따로 둔다.
- `PackagesPanel`은 종류 하나만 보인다. 버튼은 상태에 따라 설치, 업데이트, 켜기/적용, 켜져 있음/사용 중으로 바뀌고, 폴더 열기와 올리기도 종류별이다.
## 갱신

2026-11-15: 사용자 요청으로 라이트 스킨을 빼고 다크 토큰을 이름 그대로 **기본** 스킨 하나로 둔다. 라이트를 골라 둔 기록은 기본으로 돌아간다.
