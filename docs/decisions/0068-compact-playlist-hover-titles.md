# 작은 음악 목록과 hover 제목 이동

2026-10-27: 음악 목록의 긴 제목은 항목에 마우스를 올린 동안만 좌우 이동해 끝까지 읽을 수 있게 한다. 기존 토스트의 제목 렌더러를 Desktop/DashboardMusic/MusicTitleLine으로 옮겨 같은 clip·ink 수직 중앙·왕복 animation을 두 실제 화면에서 재사용한다. 토스트는 보이는 동안 이동하고 목록은 해당 행의 hover 동안만 이동한다. 짧은 제목은 움직이지 않고 비활성 목록 제목은 말줄임표로 표시한다. 항목 이탈·접기·숨김·목록 교체·해제 시 animation을 중지하고 시작 위치로 돌린다. 제목 이동은 클릭/키보드 재생·안쪽 휴지통 삭제에 관여하지 않는다.

음악 전용 행의 안쪽 여백을 좌우10/상하4 DIP, 휴지통을26 DIP, 항목 간격을4 DIP로 줄여 항목 높이를52에서34 DIP로 줄인다. 목록의 최대 높이는150에서114 DIP로 줄이고 카드 상하 여백·제어 간격·곡 추가 행도 줄인다. 공통 disclosure 스타일·행 배경·모서리·hover 언어는 유지하며 일반 할 일 항목은 변경하지 않는다. 중앙 대시보드와232 DIP 카드 폭·볼륨·재생 수명은 보존한다.

후속 요청에 따라 플레이어 상단 현재 제목에도 MusicTitleLine을 사용한다. 상단은18 DIP 행·기존12 DIP SemiBold를 유지하며 추가 정정에 따라 긴 제목을 해당 제목 영역에 마우스를 올린 동안만 이동하고 이탈하면 처음 위치의 말줄임표 표시로 돌린다. 짧은 제목은 고정한다. 같은 제목 갱신은 위치를 유지하고 제목 변경·숨김·해제는 clock을 정리한다. 토스트·상단·목록의 실제 세 화면에서 같은 renderer를 재사용한다.

추가 요청에 따라 상단·목록의 hover 제목은 최초1.2초 대기 없이 즉시 이동하고 속도를28에서36 DIP/초로 약29% 높인다. 왕복 양 끝의1.2초 읽기 대기는 유지한다. 토스트의 자동 이동 속도·최초 대기는 유지한다.

화면 밖 WPF 검사로 hover 이전 정지·긴 제목의 즉시 이동과 실제 이동 속도·짧은 제목 정지·이탈/접기/교체/해제 정리, 실제 항목/카드 높이와 클릭·삭제 회귀를 확인한다. 상단 제목의 hover 전 정지·진입 시 이동·이탈 시 초기화·동일 제목 연속 이동·짧은 제목 전환·숨김/재표시 후 새 hover 대기·해제도 확인한다.
