# 캡처 도구가 전경일 때만 오버레이가 양보

2026-11-06: ADR 0025의 "캡처 도구 창이 보이면 Topmost 해제"를 "캡처 도구가 전경 창이면 Topmost 해제"로 바꾼다. 화면 녹화 중에는 캡처 도구 창이 계속 보이므로 기존 규칙으로는 오버레이를 앞으로 가져와 녹화할 수 없었다.

- 영역 선택 UI나 편집 창이 전경이면 지금처럼 오버레이가 그 아래로 내려간다.
- 도구가 전경을 벗어나면 창이 보이더라도 Topmost를 복구한다. 이때 포커스는 빼앗지 않는다.
- 단축키·트레이 등으로 여는 명시적 열기는 도구가 전경이어도 맨 앞에 활성화한다.
- 한계: 맨 앞의 전체 화면 오버레이는 녹화 도구 막대를 가릴 수 있다. 녹화를 끝내려면 오버레이를 먼저 숨긴다.
