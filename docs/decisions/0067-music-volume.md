# 음악 소리 크기

2026-10-27: 음악 리모컨에 재생 위치와 같은 디자인의 소리 슬라이더와 퍼센트를 추가한다. 0~100%를 지원하며0은 음소거이고 재생 위치·재생 상태는 계속 유지한다. 기존 소리 크기에 맞춰 구형 데이터의 기본값은50%로 둔다.

Core/YouTubePlaylist에 선택적 VolumePercent(int, 기본50,0~100)를 추가하고 Copy·검증·기존 암호화 Store 저장에 포함한다. schemaVersion2와 기존 목록·반복은 보존한다. MusicPlaybackService가 현재 볼륨·저장 대기·실패 안내를 소유하고 IMusicTransport.SetVolumeAsync로 전달한다. LocalMusicTransport는 MediaPlayer.Volume에0~1로 적용하며 처음 재생·곡 변경에도 재생 전에 현재 볼륨을 적용한다. 시스템 소리 API나 오디오 파일은 변경하지 않는다.

슬라이더 이동은 즉시 소리에 반영하고300ms 입력 중단 후 최신 값만 저장한다. 숨김·종료 전 TrySaveEdits는 남은 볼륨 저장을 확인한다. 저장 실패는 현재 볼륨·초안을 유지하고 재시도를 제공하며 음악을 멈추지 않는다. 목록 저장은 현재 볼륨을 함께 보존해 늦은 재시도 때문에 예전 값으로 덮어쓰지 않는다. UI 숨김·패널 해제·다음 곡·반복에서도 Controller 소유 수명을 유지한다.

Core 검사로 구형 기본값·복사·왕복·범위 거절을, 합성 WPF/native 검사로 즉시 적용·0/100·저장 실패 재시도·재시작·목록 편집·곡 전환의 볼륨 유지를 확인한다.
