# 플러그인 위젯 저장소·설정 구역·탭/위젯 조회

2026-11-04: 플러그인이 탭과 위젯을 ID로 가리키고, 위젯별 데이터를 앱 기록에 두며, 플러그인별 설정 구역을 선언할 수 있게 한다. [0073](0073-widget-grid-and-plugins.md)의 "계약을 통해서는 사용자 기록을 읽을 수 없다"를 위젯 저장소에 한해 좁힌다. 일정·수면 같은 다른 기록은 여전히 노출하지 않는다.

## 결정

- **ID**: 탭은 `WorkspaceTab.Id`, 플러그인은 manifest `id`, 위젯 종류는 전역 `plugin.<플러그인>.<위젯>` 또는 `builtin.*`, 배치된 위젯은 배치 ID다. 같은 위젯이 다른 탭에 놓이면 배치 ID와 저장소가 다른 별개의 위젯이다.
- **조회**: `IFacetWorkspace`로 탭 목록, 탭 → 위젯, 위젯 종류 ID → 모든 탭의 배치를 얻는다. 다른 위젯의 저장소는 읽기 전용 타입으로만 받는다.
- **저장소**: 위젯이 `UsesData`를 선언하면 앱이 배치 때 `AppData.WidgetStores[배치 ID]`를 만들고 DPAPI 기록과 함께 저장한다. 배치나 탭을 지우면 저장소도 지운다. 플러그인을 꺼도 배치가 남으므로 저장소는 남는다. 저장소당 200개 키, 값 64K자로 제한한다. 쓰기마다 전체 기록을 저장하므로 잦은 쓰기용이 아니다.
- **배치 규칙**: `AllowMultiple`은 한 탭 안의 복수 배치, `AllowMultipleTabs`는 여러 탭 배치다. 내장 위젯은 둘 다 false다.
- **설정 구역**: `IWidgetRegistry.AddSettings`로 슬라이더·색상·텍스트·텍스트 목록·선택·동작 버튼 필드를 선언한다. 선언하지 않으면 구역이 없다. 앱이 그리고 선언 범위로 검증해 `AppData.PluginSettings[플러그인][키]`에 저장한다.
- **날씨 설정 이전**: 네이티브 "날씨 위치" 그룹을 없애고 날씨 플러그인 구역으로 옮긴다. 값은 로드 때 `Settings.WeatherRegionId`에서 한 번 복사한다. 내장 날씨 위젯과 `facet_weather` 도구도 `PluginData.WeatherRegion`으로 같은 값을 읽는다. 플러그인 설정에 코어가 의존하는 유일한 예외이며, 내장 날씨를 없앨 때 함께 제거한다.

- **다시 불러오기**: 플러그인별 버튼이 재시작 없이 폴더의 파일로 어셈블리와 위젯을 교체한다. 사용자가 누른 동작을 현재 파일의 승인으로 보고 해시를 갱신하므로, 켠 적 있는 플러그인에만 표시한다. 실패하면 이전 승인을 유지한다. WPF 타입이 어셈블리를 붙잡으므로 언로드하지 않아 이전 코드는 재시작까지 메모리에 남는다.

## 한계

켠 플러그인은 모든 위젯 저장소를 읽을 수 있다. 샌드박스가 아니므로 [0073](0073-widget-grid-and-plugins.md)의 한계도 그대로다. 날씨 플러그인이 없거나 꺼져 있으면 지역을 바꿀 화면이 없고 마지막 값을 계속 쓴다.
