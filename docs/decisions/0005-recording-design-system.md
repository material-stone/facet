# 0005 — 기록 중심 디자인 시스템

사용자 피드백: 정보 밀도와 장황한 문구 때문에 집중 대상이 불명확하다. Desktop 표현 경계에서만 재구성한다. Core 일정·기록·DPAPI 형식은 유지한다.

공통 Tokens.xaml + Components.xaml 리소스를 사용한다. 밝은 중성 배경, 높은 대비 본문, 짙은 녹색 주 행동, 4/8 기반 간격, 12/14/18/24 글자 계층을 적용한다. 오늘 화면은 목록/선택 항목 입력으로 나누고 긴 절차·계획 설정·과거 이력은 접는다. 수면은 기본 기록을 먼저, 제작은 결과/다음 행동을 먼저 보여 준다. 기능과 저장된 상세 내용을 제거하지 않는다.

검증: Release 빌드, 기존 Core 검사, 별도 데이터에서 실제 기록 저장/전환과 작은 창 레이아웃 확인. 사용자 데이터에 디자인 테스트 기록을 쓰지 않는다.
