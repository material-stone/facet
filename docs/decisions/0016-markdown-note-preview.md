# 마크다운 노트 보기와 편집

2026-10-24: 날짜 패널의 노트는 기본적으로 테두리가 있고 포커스를 받을 수 있는 읽기 전용 영역이다. 클릭 또는 Enter로 원문 TextBox를 표시하며, 편집 중 Esc는 기존 저장 경로로 변경을 저장한 뒤 마크다운 보기로 돌아가 영역에 포커스를 유지한다. 원문 입력란이 키보드 포커스를 잃어도 저장 후 보기로 돌아가되 새 대상의 포커스를 유지한다. 저장에 실패하면 원문과 편집 모드를 보존하고 오버레이를 닫지 않는다. 보기에서 Esc는 오버레이를 닫는다. 날짜 이동 시에도 기존 초안을 저장하고 새 날짜는 보기 모드로 연다.

Tab은 선택된 탭 → 현재 선택 날짜 → 새 할 일 입력란 → 각 할 일 항목 → 노트 보기 순으로 순환하고 Shift+Tab은 역순이다. 날짜를 위한 포커스가 필요하면 선택 날짜가 있는 월을 표시한다. 날짜에 포커스가 있으면 좌우 방향키는 하루, 위아래는 7일씩 선택을 이동하며 월·연도 경계를 넘어 해당 날짜의 패널과 포커스를 함께 갱신한다. 최소·최대 날짜를 벗어나지 않고 저장 실패 시 기존 선택과 초안을 유지한다. 월 이동/오늘 버튼과 다른 날짜들은 Tab 순서에 끼지 않는다. 노트 편집 중 Tab도 원문에 탭 문자를 넣는 대신 포커스를 이동한다.

할 일은 별도 체크박스·삭제 버튼 없이 읽기용 항목 자체에 포커스를 받는다. 항목 클릭 또는 Space/Enter로 완료를 토글하고 완료 텍스트에는 취소선을 적용한다. 포커스된 항목에서 Del을 누르면 그 항목만 삭제하고 다음 항목, 이전 항목, 빈 목록의 입력란 순으로 포커스를 복구한다. 새 할 일 입력란 옆의 추가 버튼은 제거하며 Enter·입력란 포커스 이탈 시 확정하고 저장한다. 노트와 완료·삭제 변경은 자동 저장하고 변경이 없으면 저장하지 않는다. 항목 추가·토글 시 기존 컨트롤을 유지해 포커스가 유실되지 않게 한다. 저장 버튼은 표시하지 않는다.

정규식으로 문법을 직접 파싱하는 대신 Desktop에 고정 버전 Markdig 1.4.2를 추가한다. NuGet.Config는 공식 nuget.org의 Markdig만 허용한다. OverlayNoteMarkdown은 AST를 WPF TextBlock·Span·Grid로 렌더한다. 제목, 강조, 목록·체크 목록, 인용, 코드, 구분선, 표를 표시한다. 링크와 이미지 대체 텍스트는 글자로 표시하며 네트워크나 외부 프로그램을 열지 않는다. HTML은 문자로 표시한다. Core는 Markdown 파서에 의존하지 않고 암호화 저장에는 편집한 원문을 그대로 유지한다.

달력의 Viewbox를 자연 높이로 중앙 정렬하고 날짜 패널 높이를 실제 표시된 달력 높이에 바인딩한다. 작은 화면에서는 패널 제목과 여백을 줄이고 본문 스크롤을 유지한다. 탭 묶음·달력·패널에 같은 그림자를 적용한다. 화면 배경의 캡처와 블러 수명은 변경하지 않는다.

검증은 화면 밖 WPF에서 클릭·Enter·Esc, 원문 저장과 렌더 결과, 날짜 격리, 실패 보존, 보기 포커스, 크기별 높이 일치·본문 스크롤·그림자 렌더로 수행한다.
