# 오버레이 설정 탭과 검색

2026-10-24: 오버레이 가장 오른쪽에 설정 탭을 추가한다. OverlaySettingsView는 최대 폭 800 DIP의 중앙 영역에서 탭 아래 24 DIP 여백 후 검색 입력을 먼저 배치한다. 그룹 이름·구분선·설정별 한 행으로 표시하고 이름은 왼쪽, 편집 컨트롤은 오른쪽에 둔다. 이름 hover에는 설명 툴팁을 제공한다. 공통 스크롤바와 디자인 토큰을 재사용한다.

검색어는 공백으로 나눈 모든 키워드를 이름·설명·현재 입력값에서 대소문자 구분 없이 찾는다. 일치 행만 남기고 빈 그룹은 숨기며 이름과 검색 중 표시하는 설명·값 요약의 일치 부분을 강조한다. 행을 숨겨도 편집 컨트롤을 재생성하지 않아 검색 전환·탭 이동 중 초안을 유지한다. 결과가 없으면 안내를 표시한다.

SettingsEditing은 두 설정 화면의 시간 관계 검증과 Windows 시작 등록을 공유한다. 새 화면은 변경한 항목만 최신 Settings 복사본에 적용해 현재 표시 상태 등 다른 설정을 보존한다. 기존 Controller.ApplySettings의 단축키 등록·암호화 저장·날씨 갱신을 사용하며 저장 버튼과 Ctrl+S, 기존 오버레이 이탈 저장 경로로 저장한다. 실패하면 인라인 오류와 초안을 유지한다. 관리 창에 미저장 설정이 있으면 먼저 그 초안을 처리하도록 안내하며 덮어쓰지 않는다. 저장 후 깨끗한 관리 창은 갱신한다. 위치 권한은 기존 전경 버튼 동작에서만 요청한다. 저장 형식과 Core의 의존성은 바꾸지 않는다.

화면 밖 WPF 검사에서 탭 순환, 800 DIP 제한·여백·스크롤, 이름/설명/값 검색과 강조, 빈 결과, 검색 중 초안 보존, 검증 실패·재시도와 합성 저장소 왕복을 확인한다. 실제 사용자 설정·자동 시작 등록·위치 권한은 검사하지 않는다.
