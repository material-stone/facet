# ADR 0108: 위젯 기본 크기와 늘이기 배치, 오른쪽 위 아이콘 메뉴

2026-11-17: 스킨이 위젯과 탭의 외형을 정의하는 구조([0109](0109-skin-widget-layer.md))를 위해 배치와 메뉴를 바꾼다.

## 결정

- **위젯 기본 크기:** `WidgetDescriptor`에 기본 크기 `Width`, `Height`(px)를 둔다. 값이 없으면 예전 `DefaultColumns`/`DefaultRows`에 기본 칸 크기(96px)를 곱한다.
- **배치는 px:** `WidgetPlacement`는 보드 좌표 px로 위치와 크기를 저장한다. 예전 칸 단위 배치는 한 번 읽을 때 칸 크기를 곱해 옮긴다(`GridVersion` 7).
- **늘이기:** 위젯 내용은 항상 기본 크기로 배치한 뒤 타일 크기에 맞춰 가로와 세로를 따로 늘이거나 줄인다(stretch). 100×200 위젯을 50×400으로 놓으면 내용이 가로로 절반, 세로로 두 배가 된다. 드래그 중에도 내용이 실시간으로 그 크기로 보인다.
- **크기 조절 모드:** 모서리를 끌면 기본은 자유 늘이기이고, Shift를 누른 채 끌면 지금 타일의 가로세로 비율을 유지한다. Alt를 누른 채 끌면 그 순간만 스냅을 반대로 쓴다.
- **격자 스냅:** 편집 중 끄고 켤 수 있다(기본 켜짐). 켜면 위치와 크기가 격자 칸에 붙고, 끄면 1px 단위다. 격자 칸 크기는 2px부터 1px 단위로 고른다. 겹침 금지는 그대로다.
- **새 위젯:** 지금 보이는 화면의 가운데에 기본 크기로 추가한다. 그 자리가 막혀 있으면 가장 가까운 빈자리로 옮긴다.
- **아이콘 메뉴:** 설정은 탭에서 빠진다. 오버레이 오른쪽 위 고정 위치(여백 24px)에 아이콘 버튼 두 개를 둔다: 위젯 편집, 설정. 테두리와 배경이 없고 호버하면 강조된다. 설정은 모달 창으로 열리고 Esc로 닫는다. 편집 중 도구(위젯 추가, 원점, 스냅, 완료)는 이 메뉴 옆에 나온다.
- **탭 막대는 위젯:** 탭 막대는 앱이 제공하는 위젯이다. 사용자가 옮기고 크기를 바꿀 수 있고, 배치 하나를 모든 탭이 같이 쓴다. 외형은 스킨이 바꿀 수 있다([0109](0109-skin-widget-layer.md)).
- 탭 목록에서 설정이 사라지므로 [0085](0085-ordinary-tabs.md)의 "설정 탭은 필수"를 대체한다.

## 결과

- 위젯 크기가 칸에 묶이지 않는다. 늘인 위젯은 글자도 같이 늘어나므로 비율을 크게 바꾸면 찌그러져 보일 수 있다. 사용자가 고른 것이다.
- 위젯 뷰의 반응형 배치(작은 타일에서 줄 숨기기 등)는 기본 크기 안에서만 의미가 있다.
