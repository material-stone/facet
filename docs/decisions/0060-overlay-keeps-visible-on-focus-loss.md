# 포커스 이탈 시 오버레이 유지

2026-10-25: 사용자는 Win+Alt+O로 연 직후 간헐적으로 닫히는 문제를 줄이기 위해 포커스 이탈 자동 숨김을 제거하도록 요청했다. 0027의 주 모니터 배치는 유지하고 비활성화 시 숨김 정책만 대체한다.

일반 오버레이와 빠른 실행은 다른 창으로 포커스가 이동해도 표시 요청·입력·배경을 유지한다. OverlayWindow.Deactivated는 캡처 도구에 따른 Topmost 갱신만 수행하며 HideOverlay를 호출하지 않는다. 스냅샷용 임시 Hide에만 쓰던 비활성화 예외 상태도 제거한다. 표시 도중 비활성화가 발생해도 닫기 요청이 끼어들지 않는다.

Win+Alt+O·Win+Alt+Space 토글, 모드별 Esc, 빠른 실행 내부의 바깥 클릭과 명시적 숨김은 기존 저장·페이드 경로를 유지한다. 캡처 도구가 보이면 Topmost를 양보하고 도구 종료 후 포커스를 빼앗지 않고 복구한다. Core·저장 스키마·단축키 등록은 변경하지 않는다.

화면 밖 검사는 두 모드의 비활성화 후 표시 요청과 빠른 실행 입력 보존·기존 바깥 클릭 닫기를 확인한다. 별도 --overlay-focus 검사는 다른 창으로 포커스를 옮긴 뒤 표시 유지·주기 갱신·명시적 숨김과 캡처 도구 우선 표시를 확인한다. 실제 배경 캡처와 전역 키 입력은 사용하지 않는다.
