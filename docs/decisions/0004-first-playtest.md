# 0004 — 실제 프로젝트에 맞춘 첫날 테스트

사용자가 두 프로젝트를 읽고 오늘의 테스트 범위를 앱에 저장하도록 요청했다. Core의 FirstPlaytest가 프로젝트별 절차와 미실행 결과 양식을 소유한다. game-01 상세에 요약을 표시하고 전용 두 버튼에서 WorkItem을 연다. 시작일/프로젝트/범위 버전으로 SourcePlanKey를 만들고 없는 작업만 추가한다. 이미 작성한 메모·집중·보관 상태는 유지한다. 기존 DPAPI Save의 원자적 교체와 백업을 그대로 사용하며 데이터 스키마는 2를 유지한다.

게임 소스와 문서의 정적 확인은 실제 게임 실행, 초심자 이해도, 출시 검증과 구분한다. 빈 결과 양식은 미실행으로 명시하며 단계는 채택이다. 실제 게임 파일·가격·배포 상태는 변경하지 않는다.
