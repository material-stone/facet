# 날짜별 할 일과 노트

2026-10-24: 오버레이 달력의 날짜를 클릭하면 해당 날짜의 할 일과 노트를 작성한다. 탭 이름은 달력으로 변경하고 감싸는 프레임 없이 버튼을 이어 붙인다. 양 끝 버튼에만 바깥 모서리를 둥글게 적용한다. 달력과 탭에는 툴팁을 표시하지 않으며 기존 월·오늘·탭 단축키는 유지한다.

Core/CalendarNotes는 AppData schemaVersion 2의 선택 목록 CalendarDays와 날짜별 CalendarDayEntry/CalendarTodo를 소유한다. 이전 파일은 빈 목록으로 읽는다. 같은 날짜는 한 항목으로 갱신하고 빈 노트·빈 목록은 제거한다. 다른 수면·제작·계획 기록과 독립적이며 미래 날짜도 작성할 수 있다. 기존 Store의 DPAPI·원자적 교체·백업을 재사용한다. AI 스냅샷에는 포함하지 않는다.

Desktop/OverlayCalendarView는 클릭 가능한 날짜와 기록 표시를 소유하고, OverlayDayEditor는 달력을 유지한 채 오른쪽 패널에 선택한 날짜의 내용을 항상 표시한다. 처음에는 오늘을 선택하고 저장된 내용을 불러온다. 달력에서 다른 날짜를 클릭하면 기존 초안을 저장하고 패널 내용을 전환한다. 오늘은 밝은 배경만, 선택 날짜는 테두리로 구분한다. 오늘을 선택하면 두 표시를 함께 적용한다. 오늘 버튼과 Home은 오늘을 선택하고 해당 월과 내용을 표시한다. 좁은 화면에서도 좌우로 배치하되 패널 본문은 스크롤한다. 할 일 추가·수정·완료·삭제와 여러 줄 노트를 지원한다. 입력 정지 후 자동 저장하며 날짜/화면 이동·오버레이 숨김·정상 종료 전에 남은 입력을 저장한다. 저장 실패 시 기존 데이터와 초안을 보존하고 이동을 막는다. 패널 닫기 버튼은 없으며 Esc는 저장 후 오버레이를 닫는다. 텍스트 입력에 포커스가 있을 때 Home/Page Up/Page Down은 입력의 기본 동작을 보존한다.

검증은 Core의 날짜 격리·검증 실패 무변경·직렬화 호환과 별도 데이터 저장소의 암호화 재읽기, 날짜 클릭·편집·자동 저장·실패 보존·툴팁 제거·붙은 탭 모서리·크기별 렌더로 수행한다. 배경 캡처·블러는 변경하지 않는다.

후속 결정 [0016](0016-markdown-note-preview.md)은 노트를 기본 보기 모드로 표시하고 편집 중 Esc를 저장 후 보기 복귀로 변경하며, 달력·패널 높이 일치와 그림자를 정의한다.
선택 날짜의 방향키 이동과 할 일 항목 클릭·Space/Enter 완료 전환·취소선·Del 삭제 및 버튼 제거도 0016의 입력 정책을 따른다.
