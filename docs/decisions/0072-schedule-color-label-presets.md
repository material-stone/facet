# 일정 색상·레이블 프리셋

2026-11-01: 새 일정/일정 수정 창의 색상 코드 입력·레이블 입력·고정 색상 8개를 하나의 **색상 · 레이블 버튼**(색상 견본 + 레이블 한 줄)으로 바꾼다. 일정의 색상/레이블은 프리셋으로만 고른다.

- 버튼을 누르면 날짜·시간 선택과 같은 ScheduleTimeHost 앵커 레이어에 `OverlaySchedulePresetPicker`가 뜬다. 프리셋은 추가 클릭 없이 바로 펼쳐진 목록(최대 높이 264 DIP, 넘치면 세로 스크롤)으로 보이며, 행을 클릭하거나 Enter/Space로 고르면 즉시 초안에 반영하고 닫는다. 각 행 끝의 휴지통 버튼은 선택 없이 그 프리셋을 바로 저장소에서 제거한다.
- 아래 **새 프리셋 추가** 버튼은 같은 레이어에서 `OverlaySchedulePresetDialog`로 바꾼다. 색상 박스를 누르면 기존 `OverlayScheduleColorPicker`가 대화상자 안에 펼쳐지고, 레이블(1~40자)과 함께 확인으로 저장·적용하며 취소는 목록으로 돌아간다. 저장 실패 시 대화상자와 입력을 유지한다.
- Esc 순서: 색상 선택 → 추가 대화상자 → 콤보 드롭다운 → 프리셋 목록 → (기존) 일정 저장. 레이어 바깥 클릭은 프리셋 레이어만 닫는다.
- 저장: AppData 선택 필드 `SchedulePresets`(최대 50, `#RRGGBB` 대문자 + 레이블, 중복 없음). 필드가 없으면 기존 일정에서 쓴 색상/레이블을 최근 날짜 순으로 파생해 보여 주며 첫 추가/삭제 때 실체화한다. 손상된 항목은 로드 시 버린다. 프리셋 삭제는 기존 일정의 색상/레이블을 바꾸지 않는다.
