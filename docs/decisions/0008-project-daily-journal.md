# 0008 — 연결 프로젝트의 날짜별 제작 일지

2026-10-17: 제작 화면에서 각각의 프로젝트 루트를 연결하고 새로고침으로 오늘 작업을 AI에 정리시켜 일지·달력·다음 행동 코멘트를 보려는 요청을 구현한다.

Core/ProjectJournal은 연결 프로젝트, 날짜별 일지, 구조화 응답 검증과 projectId/date upsert를 소유한다. AppData v2에 선택적 Projects/ProjectJournals 목록을 추가한다. Desktop은 기존 Store의 암호화·백업과 CodexRoadmapAgent의 격리 실행을 재사용한다. AI 로드맵의 선택 적용과 별개로 새로고침 자체가 일지 저장 요청이며 제작 작업·실제 단계는 변경하지 않는다.

Desktop/ProjectActivityCollector는 로컬 날짜의 Git 커밋, 허용된 파일의 미커밋 diff, 오늘 수정된 파일의 제한된 본문, README와 파일 목록을 수집한다. Git 저장소가 없으면 수정 시각 기반으로 분석하되 오늘 실제 작업의 확증으로 취급하지 않는다. 미커밋 diff에는 이전 날짜 작업도 있을 수 있다고 명시한다. 소스와 문서는 크기·개수 제한을 적용하며 누락과 자른 자료를 표시한다. reparse point, 외부 경로, 비밀 이름, 생성물, 앱 기록 경로를 제외한다. Git 외부 diff/textconv/optional locks를 비활성화한다. 분석 Agent에는 도구를 주지 않고 파일을 명령으로 실행하지 않는다.

제작 탭 안의 기본 화면은 프로젝트 일지이며 상세 작업 편집은 같은 탭의 보조 화면에 보존한다. 프로젝트 이름과 폴더 선택, 연결 해제(일지 보존), 재연결, 개별/전체 새로고침, 취소와 상태를 제공한다. 월별 달력은 저장된 기록이 있는 날을 표시하고 날짜 선택으로 작업 요약·근거 범위·마지막 코멘트를 표시한다. 같은 날 재실행은 중복 생성하지 않는다. 날짜는 시작 시 고정하고 실패/취소 시 기존 일지는 유지한다.

검증: Core 형식·중복·날짜·연결 충돌·기존 v2 roundtrip, 합성 Git/일반 폴더 수집과 제외·경로 제한, 암호화 재로드, 격리 WPF 렌더와 실제 Codex 응답. architecture 명령은 아직 null이므로 선언 경계는 직접 점검한다.

JournalChecks는 검증 전용으로 Desktop/Core를 참조한다. scripts/check.ps1은 기존 Core 검사와 JournalChecks를 함께 실행하며 실제 AI 연결은 --live로 분리한다. 이미지·음원·영상·모델은 본문 없이 이름과 수정 시각만 수집한다.
