# 버튼에 연결된 독립 날짜·시간 선택 창

2026-10-25: 일정 수정 창 내부 Grid의 고정 높이580 선택 창이 부모의 자동 크기 계산에 참여해 열 때 부모 높이가 바뀌었다. 날짜·시간 선택 UI는 OverlayTabs의 전체 모달 레이어 안에 있는 별도 Canvas에서 표시한다. Canvas는 부모의 측정 크기에 참여하지 않고 버튼의 화면 좌표 아래에 배치하며 화면 가장자리와 남은 높이에 맞춰 폭/스크롤을 제한한다. 운영체제 팝업 창을 추가하지 않아 기존 오버레이 활성화와 Esc 경계를 유지한다.

OverlayScheduleEditor는 시간 범위 초안과 열기/닫기 이벤트를 소유하고 OverlayTabs는 선택 창의 배치/바깥 클릭을 소유한다. 선택값 변경은 즉시 초안과 버튼에 반영한다. 선택 창의 확인/취소와 하단 시작→끝 요약은 제거한다. Esc/바깥 클릭은 현재 값을 유지한 채 선택 창만 닫으며 일정 수정 창은 확인/취소 버튼 없이 Esc·바깥 클릭으로 전체 초안을 저장한 뒤 닫고 기존 일정의 삭제 버튼만 제공한다. 검증/저장 실패 시에는 수정 창과 초안을 유지한다. 새 일정의 현재 이름/내용이 모두 공백뿐이면 범위/색상/레이블 변경에 관계없이 commit 없이 닫으며 기존 일정에는 적용하지 않는다. 내용이 있는 새 일정은 이름 없이도 자동 저장하며 다이얼은 내용의 첫 텍스트 줄을 표시용 레이블로만 사용한다(0051). 날짜 범위/30분 간격/최소 기간 검증은 기존 로직을 재사용한다. 작은 달력과 시간 입력을 내용 높이에 맞춰 표시하고 높이가 부족할 때만 스크롤한다.

검증: build.ps1 -OverlayUi의 배포 보존24·Core76·WPF811 검사와 실제 전경 입력27 검사 통과. 1440×900/800×600/480×360에서 부모 위치·크기 보존, 버튼 아래 배치와 화면 경계, 즉시 초안 반영, 바깥 클릭/Esc의 최상위 선택 창 닫기, 별도 확인/취소·하단 요약 제거를 확인했다. 렌더 이미지에서 컴팩트한 작은 달력과 시간 입력을 확인했다. 환경 검증 PASS이며 architecture 명령 null 경고는 기존대로다. 배포본은 1.14.4-20261025-060926-67de8f63이다.
