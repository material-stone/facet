# 오버레이 투명도와 배경색 팔레트

2026-10-25: 배경 진하기 대신 투명도 0–100%를 사용한다. 0%는 선택 배경색으로 완전 불투명, 100%는 배경이 완전 투명하다. 글자·탭·입력의 불투명도는 바꾸지 않는다.

Settings에 선택 필드 OverlayTransparencyPercent와 OverlayBackgroundColor를 추가한다. 기존 Opacity는 구버전 호환을 위해 보존한다. 투명도가 없는 기록은 기존 0.4–1 범위 Opacity와 OverlayBackdrop의 60% alpha를 합쳐 투명도로 읽어 기존 모습을 보존한다. 색상 누락 기본값은 #141A1D다. 두 설정 화면은 동일한 팔레트와 변환·검증을 사용한다. 오버레이 설정은 즉시 자동 저장하고 관리 창은 기존 저장·미저장 보호 정책을 따른다.

OverlayWindow는 배경 RGB와 진하기를 함께 적용하며 완전 투명일 때는 블러와 스냅샷도 해제한다. 배경색 변경은 기존 표시 상태·전경 포커스·전환을 유지한다. 블러 0의 단순 반투명 경로는 화면 캡처 없이 뒤 화면을 보여 준다. 선택적인 기존 블러 설정과 빠른 실행의 투명 배경 정책은 유지한다. Windows의 전역 투명 효과는 변경하지 않는다.

검증은 투명도 양끝·중간값, 구버전 진하기 변환, 색상/투명도의 암호화 저장·재로드, 팔레트 선택과 자동 저장 실패·재시도, 두 설정 화면의 일관성, 배경 alpha와 전경 유지·100% 시 캡처 미시작을 확인한다.
