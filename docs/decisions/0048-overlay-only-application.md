# 0048 — 일반 관리 창과 전용 기능 제거

2026-10-25: 앱의 사용자 화면을 전체 화면 오버레이와 빠른 실행으로 한정한다. MainWindow와 기존 대시보드·실천 계획·수면 기록·제작 작업·프로젝트 일지·AI 로드맵·알림 이력·수동 백업/복원 화면 및 전용 실행 코드를 제거한다. 기존 계획과 테스트 작업을 시작 때 생성하지 않으며 수면·저녁 준비 예약 알림도 실행하지 않는다.

Controller는 OverlayWindow의 숨겨진 상태에서도 유지되는 HWND로 전역 단축키와 화면 변경 메시지를 받는다. 전역 단축키는 오버레이·빠른 실행·종료 세 개다. 수면·제작 단축키와 일반 창을 여는 트레이 항목을 제거한다. 사용자 알림 CLI와 토스트는 유지하고 열기 버튼은 오버레이로 연결한다. 설정은 오버레이 자동 저장 화면 하나만 사용한다. 시작 복구·업데이트 실패 안내는 트레이에서 표시하며 저장 실패는 호출 화면의 초안·재시도 경계로 반환한다.

정상 종료·업데이트 요청은 오버레이 편집 저장에 성공한 경우만 진행한다. 저장 실패는 종료를 취소하고 초안을 보존한다. Dispatcher와 Codex 채팅 수명은 Controller/Overlay가 소유하며 일반 창의 존재에 의존하지 않는다. 빠른 실행에 필요한 Codex 실행 파일 검색은 기존 CodexRuntime에 옮기고 전용 로드맵 실행기는 제거한다.

AppData v1/v2의 수면·작업·계획·프로젝트 일지·구형 설정 필드는 읽기/저장 호환용 DTO로 보존한다. 기존 기록을 지우거나 데이터 마이그레이션으로 버리지 않는다. 전용 계획 계산·CSV·AI 제안·프로젝트 수집 로직은 제거한다. DPAPI·원자적 저장·자동 백업, 달력/일정/컨디션, 날씨, 빠른 실행과 Codex 채팅, 사용자 알림의 저장·전달 보장은 유지한다.

검증은 Core 검사, 합성 저장소에서의 구형 기록 보존과 무생성 시작, 세 단축키 등록/해제 및 폐기된 단축키의 미등록, 저장 실패 종료 취소, 오버레이 화면 밖 검사, 고정 실행기의 정상 종료·업데이트 검사와 Release 빌드로 수행한다. architecture 명령은 null이며 contract의 경계를 소스에서 직접 점검한다.
