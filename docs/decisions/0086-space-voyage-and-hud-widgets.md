# 우주 항해 배경과 HUD 위젯

2026-11-05: 우주 테마를 색 교체에서 "우주를 항해하는 전술 HUD"로 넓힌다. ADR 0077의 슬롯 구조와 "테마는 레이아웃과 코드를 담지 않는다"는 원칙은 유지한다.

- 새 슬롯 `voyage`(bool)와 `hudWidgets`(bool)를 추가한다. 비어 있으면 기존 화면과 같다.
- 행성은 `Design/SpaceVoyage`의 WPF `Viewport3D`로 그린다. ADR 0077의 "HLSL 대신 CPU" 판단은 배경 전체를 픽셀 단위로 계산하는 성운에만 유지한다. 행성은 구체 mesh라 GPU 합성으로 근접 통과까지 선명하고, 추가 의존성이나 셰이더 도구가 필요 없다. 소프트웨어 렌더링(tier 2 미만)에서는 행성을 그리지 않는다.
- 행성 표면은 전용 저우선 작업에서 코드로 굽는다. 암석·가스·얼음·용암·해양·사막 여섯 종류가 있고 대기색은 종류별로 다르며 암석 행성에는 대기가 없다. 에셋을 배포하지 않는다.
- `VoyagePlan`은 UI 없는 순수 계획이다. 카메라는 원점에 고정되고 행성만 +Z로 지나간다. 진행 축에서의 거리는 항상 행성(고리 포함) 반경의 1.2배 이상이라 가까이 스쳐도 관통하지 않는다.
- 행성은 최대 3개가 동시에 날고, 진행 축 옆으로 떨어진 거리가 두 행성 반경 합의 1.1배 이상이라 서로 관통하지 않는다. 먼 곳에서 작게 나타나 8초에 걸쳐 페이드 인한다. 시작 거리는 늘려도 속도는 늘리지 않는다. 대기 빛은 카메라에서 실제로 보이는 윤곽선(접선 원)에 매 프레임 맞춘다.
- 애니메이션은 보일 때만 약 30 fps로 변환만 갱신한다. 행성이 없는 구간에는 갱신 비용이 없다.
- 빈 배경을 누르면 카메라에서 퍼지는 보이지 않는 구가 행성의 mesh 선을 가까운 곳부터 밝히고 지운다. 저장하지 않는 일회성 연출이며 끝나면 선 geometry를 버린다. 구의 속도는 행성 거리와 무관하게 표면을 약 1초에 지나도록 정한다. 일정 속도면 먼 행성에서 진행이 보이지 않기 때문이다. 선은 geometry를 고정하고 밝기 띠 brush만 옮겨 셰이더 없이 만든다.
- 별은 밝기 분포와 색온도가 다른 정적 층과 주기가 다른 깜빡임 층으로 나눈다.
- `hudWidgets`가 켜지면 앱이 `WidgetTheme.HudKey` 리소스를 넣고 위젯이 `WidgetTheme.IsHud`로 표현을 고른다. 플러그인 계약의 공개 추가다. 패널은 HUD 모양을 가진 위젯만 `WidgetDescriptor.HasHudPanel`로 선언해 그린다. HUD에서는 이 값이 ADR 0077의 `HasPanel`을 대신하며, 달력·채팅처럼 선언하지 않은 위젯은 패널 없이 둔다. 다른 스킨의 위젯은 바뀌지 않는다.
- HUD 표현: 시계는 24시간 표기와 0~24시 눈금(`DayRuler`), 날씨는 이름 붙은 습도 막대, 오늘 일정은 `DaySchedules.Around`의 이전·현재·다음과 현재 일정의 메모 첫 줄이며 종료 10분 전부터 `ScheduleNow` 색, 컨디션은 현재 상태와 상태 버튼 6개, 7일 컨디션은 범례 없는 게이지다. 두 위젯은 합치지 않는다. 합치면 이미 배치한 7일 컨디션과 게이지가 겹치고 스킨마다 위젯 구성이 달라지기 때문이다. 게이지는 `ConditionHistory`의 구간 편집과 분 단위 투영을 그대로 쓴다. 음악은 같은 부품과 처리기를 테두리 버튼 한 줄과 눈금 막대로 다시 배치한다. 7일 수면은 8h·6h 고정 눈금의 꺾은선이다. 패널(`HudPanel`), 머리글, 글꼴 등 공통 모양은 `Facet.Plugins`의 `Facet.Widgets`가 소유한다. 숫자 글꼴은 파일을 배포하지 않도록 Windows 기본 Consolas를 쓴다.
- 테마는 `options` 슬롯으로 켜고 끄는 항목(id, 이름, 설명, 기본값)을 선언한다. 설정 탭은 선택한 스킨의 항목을 스킨 목록 아래에 체크박스로 보여 주고, 값은 `Settings.SkinOptions`에 `<스킨>.<항목>`으로 저장한다. 테마는 이름만 선언하고 동작은 코드가 맡는다. 우주 테마의 첫 항목은 중앙 조준선(`reticle`)이다.
- 사용자의 위젯 배치는 바꾸지 않는다. 컨디션처럼 내용이 많아진 위젯은 사용자가 크기를 조절한다.
