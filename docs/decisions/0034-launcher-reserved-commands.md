# 런처 예약 명령어

2026-10-24: > 접두사는 앱·경로 검색과 구분되는 내부 예약 명령어 검색이다. 현재 help 하나를 제공하며 후보 목록·고스트·Tab 완성·방향키·Enter·클릭을 기존 런처와 공유한다. 완성 문자열은 > help이고 이름과 설명·벡터 Help 아이콘을 목록에 표시한다. 알 수 없는 예약 명령어를 PATH 앱으로 해석하지 않는다.

LaunchCandidate.Command는 Desktop 내부의 명령 구분이며 예약 명령어는 OS 아이콘 조회나 ProcessStartInfo로 전달하지 않는다. QuickLaunchView가 help를 실행하면 입력창 위 도움말의 표시 상태만 토글하고 입력·후보를 지운 뒤 입력 포커스를 유지한다. 같은 명령을 다시 실행하면 닫는다. 도움말은 다른 검색 중에도 유지하고 입력 모드 종료·재열기에서 초기화한다.

? 입력의 도움말 동작은 제거한다. 빈 입력의 플레이스홀더 없음, 도움말의 내부 클릭·스크롤과 작은 화면의 공통 스크롤 디자인, Esc·외부 클릭·포커스 이탈 숨김은 유지한다. Core와 저장 스키마는 변경하지 않는다. 기존 0020의 ? 도움말 입력 정책은 이 결정으로 대체한다.
