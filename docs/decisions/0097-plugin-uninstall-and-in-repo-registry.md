# 0097 — 플러그인 삭제와 저장소 안 레지스트리

2026-11-14: 순정 Facet은 가볍게 두고 기능은 플러그인으로 더한다는 목표에 맞춰, 사용자 요청으로 설치처럼 삭제도 앱 안에서 하고 레지스트리를 앱 저장소로 합친다. [0088](0088-packages-and-registry.md)의 "앱 안 패키지 제거 없음"과 별도 레지스트리 저장소를 대체한다.

## 플러그인 삭제

- 설정 → 플러그인의 각 줄에 삭제 버튼을 둔다. 누르면 그 자리에서 **삭제**, **데이터까지 삭제**, **취소**를 묻는다.
- `OverlayTabs.UninstallPlugin`이 플러그인을 끄고, 모든 보드에서 그 플러그인의 위젯 배치와 위젯 저장소를 지운 뒤 폴더를 지운다. **데이터까지 삭제**면 `plugin-data/<id>` 폴더와 `<id>.dat*` 파일, 플러그인 설정도 지운다. 기본 삭제는 데이터를 남겨 다시 설치하면 이어 쓴다.
- 네이티브 DLL처럼 아직 잡혀 있는 파일이 있으면 폴더에 `.removed` 표시를 남긴다. `PluginHost.Discover`는 표시된 폴더를 목록에서 빼고 다시 지우기를 시도한다. 늦어도 앱을 다시 시작하면 지워진다.
- 포터블 패키지에서 설치된 플러그인은 0087대로 같은 패키지에서는 다시 설치되지 않는다.

## 저장소 안 레지스트리

- 레지스트리는 `material-stone/facet`의 `registry/` 폴더다. 앱은 `main`의 `registry/index.json`을 읽고, 이 저장소 릴리스의 첨부 파일만 받는다.
- 제출 양식과 워크플로는 저장소 루트의 `.github/`에 두고, 워크플로는 `registry/`에서 실행한다. 패키지 릴리스는 시험판으로 만들어 앱 릴리스의 "최신" 표시를 빼앗지 않는다.
- 별도 레지스트리 저장소(`YouHyunwoo/facet-registry`)는 쓰지 않는다.
