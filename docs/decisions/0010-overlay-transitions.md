# 배경만 표시하는 오버레이 전환

2026-10-23: 사용자가 오버레이의 모든 HUD를 제거하고 표시·숨김에 반투명 배경의 점진적 전환을 요청했다. 0009의 요약·버튼 표시를 대체한다.

OverlayWindow는 빈 포커스 영역과 배경 Brush만 소유한다. 처음 표시하기 전에 배경 Opacity를 0으로 설정하고 280ms 동안 설정된 배경 진하기로 전환한다. 닫을 때는 현재 진하기에서 0으로 전환한 뒤 실제 Window를 숨기고 Controller가 이전 앱으로 복귀시킨다.

요청 상태와 실제 Window.IsVisible은 페이드 종료까지 다를 수 있다. 전역 단축키는 요청 상태를 토글한다. 반대 요청이 오면 현재 Opacity에서 새 전환을 시작하며 이전 완료 콜백은 새 요청을 숨길 수 없다. 주기 갱신은 같은 전환을 재시작하지 않는다.

Window 전체 Opacity, 단축키·저장 스키마, Core 경계는 유지한다. 키 입력, 중간 alpha, 완료 시점, 빠른 방향 전환, 주기 갱신 및 빈 시각 트리를 합성 WPF 환경에서 검증한다.
