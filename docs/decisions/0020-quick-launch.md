# 중앙 빠른 실행 입력창

2026-10-24: Win+Alt+O 오버레이와 별개로 Win+Alt+Space 입력 모드를 제공한다. 기존 OverlayWindow의 모니터 선택·전환·포커스 복귀를 재사용하고 탭 콘텐츠 대신 QuickLaunchView를 표시한다. 모드 전환 전 날짜 편집 저장이 성공해야 한다. 입력 모드의 배경 효과 해제와 아이콘 교체 정책은 [0023](0023-quick-launch-presentation.md)에 기록했다.

- Desktop/QuickLaunchCatalog는 PATH 순서와 PATHEXT에 맞는 앱 후보를 비동기로 수집한다. 실행은 선택된 전체 경로를 사용하며 검색 입력을 shell 명령으로 해석하지 않는다.
- 접두사 없는 입력은 앱 검색, @는 절대 경로, @@는 alias 검색이다. alias·경로는 Explorer로 열며 파일은 선택 표시한다.
- `? 검색어`의 Google 검색과 기본 브라우저 아이콘은 [0058](0058-launcher-web-search.md)의 별도 입력 모드다.
- alias는 설정의 이름=절대경로 목록에서 등록하고 선택 필드 Settings.LaunchAliases로 기존 암호화 Store에 저장한다. 이전 기록에서 필드가 없으면 빈 목록이다. alias 대상이 없어져도 등록은 보존하고 열기 시 오류를 입력창에 표시한다.
- 입력란은 모니터 중앙의 둥근 사각형이고 후보가 있을 때만 아래 목록을 표시한다. 접두사가 일치하고 커서가 끝에 있을 때 고스트 완성을 표시하며 Tab/오른쪽 화살표로 수락한다. 마우스를 움직여 후보 위에 올리거나 위/아래 방향키로 이동하면 해당 후보를 선택하고 완성 문자열을 실제 입력값에 반영한다. 아이콘을 갱신하고 입력란에 포커스·끝 커서를 두어 바로 수정할 수 있게 한다. 탐색 중에는 원래 후보 목록을 유지하며 다음 직접 입력·삭제부터 반영된 문자열로 새 검색을 시작한다. 마우스는 직전에 가리킨 후보와 다른 후보로 이동할 때만 입력값을 반영한다. 같은 후보 안의 이동·재검색·아이콘 갱신은 수정 중인 텍스트와 커서·선택 영역을 유지한다. 후보는 컨테이너가 아닌 값으로 비교하고 새 입력 모드에서 초기화한다. 정지한 마우스와 아이콘 갱신은 키보드 선택을 덮어쓰지 않는다. Enter 또는 클릭 후에만 실행한다. 아이콘이 없으면 아이콘 공간도 숨긴다.
- 검색 취소·세대 번호로 이전 결과의 덮어쓰기를 방지한다. 아이콘은 제한된 캐시에 두고 native handle은 해제한다. 검색과 추천은 프로세스를 실행하지 않는다.
- Win+Alt+Space는 고정 입력 단축키로 예약하고 기존 설정과 충돌하면 등록 실패로 안내한다. 저장된 오버레이 단축키는 보존하며 신규 기본값은 Win+Alt+O이다.
- 빈 입력에는 플레이스홀더를 표시하지 않는다. 초기 ? 도움말 정책은 [0034](0034-launcher-reserved-commands.md)의 > help 예약 명령어·토글로 대체했다. 도움말 클릭·스크롤과 작은 화면의 공통 스크롤 스타일은 유지하며 입력란 중심은 이동하지 않는다.
