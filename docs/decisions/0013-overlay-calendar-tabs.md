# 오버레이 플로팅 탭과 월 달력

2026-10-23: 사용자가 상단 중앙 플로팅 탭 메뉴와 화면 중앙의 월 달력을 요청했다. 0010·0011의 HUD 없는 화면 정책을 대체하며 배경 캡처·블러·포커스 복귀·전환 역전은 유지한다.

Desktop/OverlayTabs는 둥근 직사각형 탭 헤더와 전체 오버레이를 채우는 콘텐츠를 소유한다. 첫 탭은 캘린더 하나이며 Ctrl+[와 Ctrl+]로 이전·다음 탭을 순환한다. WPF TabControl의 선택·키보드·접근성 동작을 재사용하고 탭 이동은 월을 바꾸지 않는다.

2026-10-24 후속 변경: 달력 앞에 빈 대시보드 탭을 추가하고 최초 선택은 대시보드로 한다. 기존 Dashboard 아이콘과 탭 스타일을 재사용한다. 달력의 Home·Page Up·Page Down 명령은 달력 탭에서만 처리하며 Ctrl+[/]는 두 탭을 순환한다.

OverlayCalendarView는 PC 로컬 날짜를 기준으로 현재 월을 표시한다. 연월 제목, 구분선, 일~토 7열, 월 시작 요일에 맞춘 날짜 격자로 구성하며 일요일은 빨강, 토요일은 파랑, 오늘은 테두리로 표시한다. 오버레이를 다시 열거나 열린 상태에서 날짜가 바뀌면 갱신한다. 개인 기록이나 프로젝트 일지를 읽지 않으며 Core·저장 스키마는 바뀌지 않는다.

탭 메뉴는 화면 상단 중앙, 달력은 화면 전체 기준 중앙에 배치한다. 작은 화면에서는 달력을 균일하게 축소한다. HUD는 배경과 같은 전환 진행률로 페이드한다. 합성 WPF 검증으로 실제 단축키, 선택 유지, 윤년·시작 요일·월 말, 주말 색·오늘 테두리와 크기별 배치를 확인한다.
