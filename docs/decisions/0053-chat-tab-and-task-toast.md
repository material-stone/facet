# 0053 — 채팅 탭과 런처 작업 토스트

2026-10-25: 0047의 런처 아래 답변 표시를 채팅 탭과 지속 작업 토스트로 대체한다.

런처는 접두사·모델·effort·Fast·프로젝트를 검증한 뒤 즉시 기존 숨김 페이드를 시작한다. Controller가 요청 토스트와 비동기 생성 수명을 소유하며 생성 전 실패도 토스트에서 확인한다. 토스트는 주 모니터 작업 표시줄 위에 비활성으로 표시하고 작업 상태를 반영한다. 완료·실패·중단 상태는 명시적 닫기까지 유지한다. 본문 클릭은 해당 세션의 오버레이 채팅 탭을 열고 오른쪽 닫기 버튼은 이벤트를 소비하여 토스트만 닫는다. 기존 시작·알림 토스트의 시간 정책은 보존한다.

채팅 탭은 연결로 관리하는 최근 세션 참조를 일반 채팅·프로젝트별로 접고 펼친다. 항목과 대화 머리말에 세션별 작업 상태를 표시한다. 사용자 메시지는 말풍선, 에이전트 답변은 OverlayNoteMarkdown을 재사용한다. 외부 이미지·HTML은 로드하지 않는다. 최신 대화와 이전 페이지를 agent에서 10턴씩 읽고 turn ID로 IPC 변경을 병합한다. 준비 turn은 스트림의 ID·정확한 안내문으로 숨기며, 재실행 후 API가 최초 사용자 항목을 생략하면 가장 오래된 페이지 첫 turn의 빈 사용자·정확한 READY 답변만 준비 turn으로 판별한다. 일반 사용자의 READY 메시지는 보존하고 준비 완료가 전송 전 실패를 성공으로 바꾸지 않는다. 새 세션과 기존 세션 모두 선택한 모델·effort·Fast로 전송한다. 실행 중인 동일 세션의 중복 전송은 막고 다른 세션은 독립적으로 작업한다.

하단 입력의 Enter는 전송, Shift+Enter는 줄바꿈이며 IME 확정 Enter는 전송하지 않는다. 세션을 바꿔도 미전송 초안과 그룹 펼침 상태는 메모리에서 보존한다. 자동 스크롤은 사용자가 아래를 보고 있을 때만 동작한다. 대화·초안·전체 프롬프트는 records.dat에 저장하지 않으며 Codex가 원본을 소유한다. 대화 페이지 제한은 이전 대화 더 읽기와 Codex에서 열기로 보완한다.

검증은 합성 다중 turn/역순 페이지/준비 turn 필터/중복 전송·UI 상태·토스트 입력 분리와 기존 native checks를 포함한다. 실제 연동 검사는 명시적 옵션으로 프로젝트 없는 임시 세션에서 후속 요청과 history 재조회까지 확인하고 테스트 세션을 삭제한다.
