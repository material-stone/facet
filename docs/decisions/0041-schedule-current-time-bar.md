# 일정 다이얼의 현재 시각 바

2026-10-24: 로컬 현재 시각을24시간 각도로 변환한다.00시는 위,06시는 오른쪽,12시는 아래,18시는 왼쪽이며 분·초도 각도에 포함한다. 표시 날짜와 관계없이 현재 시각을 보여준다. 원 중앙부터 바깥 테두리까지 둥근 막대를 그리며 ScheduleNow 밝은 색과 Bg 바탕선으로 일정 색상 위에서도 보이게 한다. Viewbox 축소 배율을 보정해 화면 기준 두께를 유지한다.

OverlayScheduleDial이 단일 DrawingVisual 자식을 소유하고 부모의 일정·호버·드래그·이름·안내보다 위에 합성한다. 실제 마우스 입력과 날짜 저장 모델은 기존 다이얼이 처리한다. 표시 중1초 DispatcherTimer가 시계를 읽어 RotateTransform만 갱신하며 바 도형은 크기/배율이 바뀔 때 재사용한다. 숨김·탭 이동·Unloaded 시 중지하고 다시 보이면 즉시 현재 시각에 맞춘다. 저장·외부 전송은 없고 Core는 시계/UI를 참조하지 않는다.
