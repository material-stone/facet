# 3D 월드 페이지와 글꼴을 스킨에 포함

2026-11-06: 복셀 월드의 3D 배경과 글꼴을 앱이 아니라 스킨 데이터로 옮긴다. ADR 0088의 "스킨에 실행되는 것은 없다"와 ADR 0090의 "장면 코드는 앱 소유"를 이 결정으로 바꾼다.

- 슬롯 `world`는 `{ page, scenes }`다. `page`는 스킨 폴더의 HTML 한 파일, `scenes`는 페이지에 그대로 넘기는 이름이다. 앱에 남는 것은 WebView2 창, 클릭 전달, 날씨와 표시 상태 전달뿐이다. 내장 복셀 스킨도 같은 형식이다.
- 슬롯 `fonts`는 스킨 폴더의 글꼴을 `AppFontFamily`와 `HudHeadingFont`에 연결한다.
- 페이지는 코드이므로 앱이 잠금을 강제한다. 페이지 앞에 CSP를 붙여(뒤의 정책은 좁히기만 한다) 외부 요청을 막고, 죽은 프록시와 WebRTC 정책으로 CSP 밖의 경로도 막으며, 다른 주소로의 이동과 새 창을 취소하고, 개발자 도구와 호스트 객체를 끈다. `--world-net-check`가 실제 WebView2에서 이를 시험한다.
- 날씨는 페이지가 받지 않는다. 앱이 기존 클라이언트로 받아 상태 이름만 넘긴다. 좌표, 지역, 사용자 기록은 페이지에 전달하지 않는다.
- 월드 페이지가 있는 스킨은 자동 공개하지 않고 플러그인처럼 pull request 병합을 승인으로 삼는다. 위젯 레이아웃은 플러그인의 C# 코드이므로 여전히 스킨에 들어가지 않는다.
- 한계: 페이지는 GPU를 마음껏 쓸 수 있고 화면을 임의로 그릴 수 있다. 앱은 표시 중 프레임이나 메모리를 제한하지 못한다. 글꼴 파일은 적용 중 잠길 수 있어, 스킨을 쓰는 동안 같은 스킨을 갱신하면 실패할 수 있다.
