# 빠른 실행의 투명 배경과 아이콘 교체

2026-10-24: 빠른 실행은 모니터 중앙 입력창과 후보 목록만 표시한다. OverlayWindow의 모니터 배치·입력·포커스 복귀는 재사용하되 입력 모드의 배경 alpha와 blur radius를 0으로 고정한다. 일반 오버레이에서 전환하면 기존 배경 애니메이션과 캡처 세션을 즉시 해제한다. 일반 모드로 돌아오면 저장된 오버레이 효과 설정을 다시 적용한다.

텍스트 변경 시 기존 아이콘을 지우지 않는다. 검색 대기 동안 이전 후보는 실행·완성할 수 없고 고스트도 숨긴다. 같은 대상의 완료된 아이콘은 재사용하며 새 대상의 아이콘은 조회 완료 후 교체한다. 조회가 완료된 null 또는 후보 없음만 아이콘 숨김으로 확정한다. 빈 입력과 입력 모드 종료는 표시를 초기화한다. 검색 세대 번호로 이전 입력의 늦은 아이콘 결과가 현재 화면을 바꾸지 못하게 한다. 아이콘 조회 중에도 최신 텍스트 후보가 확인되면 Enter 실행은 가능하다.

Core·저장 스키마·일반 오버레이 효과 설정은 변경하지 않는다. 화면 밖 검사에서 전환 시 배경/블러/캡처 해제와 일반 모드 설정 복원, 연속 입력·후보 변경 중 아이콘 유지와 조회 완료 후 교체를 확인한다.

입력란·후보 목록 밖의 클릭과 OverlayWindow.Deactivated는 입력 모드를 자동으로 숨긴다. 입력란에서 후보 목록으로 이동하는 내부 포커스 변경은 숨김 조건이 아니다. 투명 영역을 통과한 클릭으로 다른 앱이 활성화되면 Deactivated가 처리한다. 자동 숨김은 포커스를 이전 앱으로 복원하지 않고 진행 중 검색을 즉시 취소한다. 이미 숨김 요청 중이거나 일반 오버레이 모드이면 무시한다. 포커스 복원 정책은 숨김 저장·표시 갱신 전에 적용하여 0ms 전환에서도 새 포커스를 보존한다.
