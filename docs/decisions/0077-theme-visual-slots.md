# 테마 시각 슬롯

2026-11-05: 스킨을 색 교체에서 분위기까지 바꾸는 테마로 넓힌다. ADR 0074의 토큰 구조와 다음 시작 적용 경계는 유지하며, 첫 시제품은 내장 우주 테마다.

- 테마는 전역 개념이다. 위젯이나 플러그인이 테마를 따로 지원하지 않아도 앱이 그리는 배경과 위젯 틀이 입혀진다.
- 스킨은 토큰 XAML에 더해 선택적으로 `Design/Skins/<Id>/theme.json`과 에셋을 가진다. 코드는 없고 앱이 정한 슬롯만 채운다. 비어 있는 슬롯은 그리지 않아 기존 화면과 같다.
- 현재 슬롯: `background`(이미지), `backgroundOpacity`, `stars`(내장 별 효과의 개수), `frame`(9-slice 이미지), `frameSlice`, `framePadding`. 글꼴·아이콘·컨트롤·소리는 시제품 검증 후 추가한다. 슬롯은 쓰임이 확인된 뒤에 늘린다.
- `Design/ThemeVisuals`가 manifest의 검증과 로드를 소유한다. 에셋 이름은 같은 폴더의 PNG 파일 이름만 허용하고 수치 범위를 제한한다. 잘못된 테마는 앱 시작을 막지 않고 시각 슬롯 없이 토큰만 적용한다.
- 배경은 오버레이의 색조 위, 탭 아래에 놓이고 입력을 받지 않는다. 빠른 실행에서는 숨긴다. 사용자 오버레이 색·투명도 설정은 그대로이며, 테마 배경이 있으면 그 위에 덮인다.
- 위젯 틀은 `OverlayWorkspaceView`의 타일이 그린다. 내장·플러그인 위젯에 같게 적용되고 위젯 코드는 바뀌지 않는다.
- 별 애니메이션은 화면에 보일 때만, 초당 12프레임 이하로 실행해 전체 화면 재합성 비용을 제한한다.
- 레이아웃 변경과 코드 실행은 테마 범위가 아니다. 파일 형식은 아직 내부용이며 외부 테마는 블록 테마까지 검증한 뒤 `<data>/skins`와 함께 공개 계약으로 고정한다.
- 2026-11-05 추가, ADR 0074의 다음 시작 적용을 대체: 설정에서 스킨을 바꾸면 저장 성공 후 바로 적용한다. 참조 328곳(XAML `StaticResource` 250, C# `FindResource` 78)을 동적 참조로 옮기면 저장된 브러시까지 모두 고쳐야 하고 스타일 안의 브러시는 얼어 있어 값을 바꿀 수도 없으므로, 토큰과 `Components`를 다시 불러온 뒤 `OverlayWindow`가 탭·빠른 실행·테마 배경을 새로 만든다. 설정 탭과 스크롤 위치는 복원한다. 저장 전 편집 내용은 먼저 저장하고 실패하면 다음 시작에 적용한다. 음악 재생과 채팅 세션은 Controller 소유라 유지되고, 메모리에만 있는 채팅 입력 초안은 사라진다. 전환마다 켜진 플러그인을 다시 불러오므로 이전 어셈블리는 재시작까지 메모리에 남는다. 이미 떠 있는 토스트와 표시기는 다음에 만들 때 새 스킨을 쓴다.
- 2026-11-05 추가: 위젯은 패널이 있는 유형과 내용만 표시하는 유형으로 나뉜다. `WidgetDescriptor.HasPanel`(기본 false)로 선언하며, 패널은 타일이 그린다(테마 `frame`, 없으면 토큰 표면). 위 "모든 위젯에 틀을 입힌다"를 대체한다. 지금은 내장·플러그인 모두 패널 없음이고, 음악 위젯의 자체 카드 표면도 제거했다. 목록 속 카드처럼 내용의 일부인 표면은 유지한다.
- 2026-11-05 추가: 음악 플레이어를 패널 위젯으로 바꾼다(위 "지금은 패널 없음"과 음악 카드 표면 제거를 대체). 고정 폭 232와 목록 높이 상한 114(ADR 0068)를 없애 플레이어가 패널 안쪽을 가득 채우고, 목록은 ADR 0078에서 모달로 옮겼다. 나머지 내장 위젯의 크기 맞춤은 그대로다.
- 2026-11-05 추가: `nebulaSpeed`, `nebulaBrightness` 슬롯과 `Design/NebulaField`를 추가한다. 영상이나 HLSL 대신 노이즈 수식을 CPU로 계산한다. 추가 도구와 에셋 없이 반복 없이 흐르기 때문이다. 288x162로 전용 낮은 우선순위 스레드에서 최대 12 fps로 계산해 확대하고, 보일 때만 돌린다. 우주 테마의 고정 배경 이미지는 이것으로 대체했다.
- 2026-11-05 수정: 테마 배경도 오버레이 투명도를 따른다(위의 "그 위에 덮인다"를 대체). 불투명도는 색조와 같은 `Strength × 전환 값`이고, 100% 투명이면 접어서 애니메이션도 멈춘다.
- 2026-11-05 추가: `panelMarkLength`, `panelCornerRadius` 슬롯과 `Design/ThemePanels`를 추가한다. 앱과 플러그인에서 `Panel` 토큰을 칠하는 곳이 약 30개라 각각 고치는 대신, `Border`의 SizeChanged 클래스 처리기가 해당 표면의 모서리와 테두리 브러시를 바꾼다. 네 모서리 표시를 Border 자체 브러시로 그려 요소를 늘리지 않고 투명도·표시 상태·팝업을 그대로 따른다. 템플릿 안의 부분, 64x28보다 작은 표면, 원래 모서리 반경이 6 미만인 표면은 내용으로 보고 제외한다. 슬롯이 비어 있으면 처리기를 등록하지 않는다. 우주 테마 `frame`도 같은 모양으로 바꿨다.
- 2026-11-05 추가: `tabCornerRadius` 슬롯(기본 12)을 추가한다. 탭 바는 첫 탭과 마지막 탭의 바깥 모서리와 탭 바 면에만 이 반경을 쓴다. 템플릿 안의 탭 바 면은 위 패널 처리 대상이 아니며, 우주 테마는 0으로 각지게 한다. 모서리 표시는 탭 머리글이 덮지 않도록 그 위의 전용 층 `TabMarks`에 그린다. 표시 브러시는 벡터가 보간되어 흐려지므로 장치 해상도의 1비트 이미지로 만든다.
- 2026-11-05 추가: 우주 테마에서 `frame`을 뺀다. 음악 패널만 이미지로 그려져 다른 패널과 달라 보였기 때문이다. 위젯 패널도 토큰 표면을 그리고 같은 모서리 표시를 받는다. `frame` 슬롯 자체는 유지한다.
- 내장 테마에는 저작권이나 상표가 걸린 게임 에셋을 넣지 않는다. 우주 테마 에셋은 코드로 직접 생성했다.
