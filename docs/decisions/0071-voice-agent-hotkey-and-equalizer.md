# 음성 에이전트 단축키와 작업 표시줄 이퀄라이저

2026-10-31: 전역 단축키로 말해서 기본 에이전트(ADR 0070)와 채팅하고, 작업 표시줄 위 점 이퀄라이저로 상태와 결과를 보인다.

- `Settings.VoiceHotkey`(기본 `Win+Alt+V`, hotkey id 106)를 누르면 듣기 시작한다. 말을 멈춘 뒤 1.6초 또는 단축키를 다시 누르면 끝낸다. 8초 동안 말소리가 없으면 취소한다. 읽는 중에 누르면 읽기를 멈춘다. 트레이에도 **음성 에이전트** 항목을 둔다.
- 녹음은 `MicrophoneRecorder`가 winmm waveIn으로 `Settings.VoiceMicrophone`(장치 이름, 빈 값은 Windows 기본)에서 16 kHz mono PCM을 받는다. 이 PC에 SAPI·OneCore 한국어 인식기가 없고 WinRT 인식기는 마이크를 고를 수 없어 Windows 음성 인식은 쓰지 않는다.
- STT는 로컬 whisper.cpp(v1.9.5) `whisper-server`와 `ggml-large-v3-turbo-q5_0.bin`(574 MB)이다. 녹음을 외부로 보내지 않는다. 공식 Windows 배포에 Vulkan 빌드가 없어 `-DGGML_VULKAN=ON`으로 직접 빌드해 AMD GPU를 쓴다. 경로는 `WhisperServerPath`·`WhisperModelPath`이며 빈 값은 `%LOCALAPPDATA%\Teum\whisper`의 기본 파일이다. 데이터 폴더가 아닌 곳에 두어 기록 백업에 대용량 파일이 섞이지 않게 한다.
- `LocalWhisperTranscriber`는 녹음을 시작할 때 서버를 loopback 임의 포트로 띄워 모델을 미리 올리고 `/health`로 준비를 기다린다. Facet이 켜져 있는 동안 서버를 유지하고 종료 시 끝낸다. 인식 품질이 부족하면 모델 경로만 large-v3로 바꾼다.
- 처음에는 OpenAI 전사 API를 썼으나 녹음을 PC 밖으로 보내지 않도록 같은 날 로컬 전사로 바꾸고 API 키 저장도 없앴다.
- 전사 결과는 `Controller.LaunchChatAsync(..., toast:false)`로 런처 채팅과 같은 경로(5분 이어 보내기, 대화 기록)를 탄다. 음성 요청은 채팅 토스트 대신 이퀄라이저가 결과 카드로 바뀌고 카드를 누르면 채팅 탭을 연다.
- `VoiceReplyMode`가 `speech`면 Core `VoiceReply.Prompt`가 답변 끝에 `<speech>…</speech>` 요약을 요청한다. `VoiceReply.Split`이 요약을 떼어 내고 없으면 정리한 답변 앞부분(최대 600자)을 읽는다. TTS는 로컬 Supertonic 3(Supertone, 가중치 OpenRAIL-M, `%LOCALAPPDATA%\Teum\supertonic` 약 383 MB)이며 공식 MIT C# 예제를 `SupertonicSpeech`로 옮겼다. 목소리는 `VoiceSpeechVoice`(기본 F1)다. 공개 패키지의 프리셋은 F1…F5·M1…M5 10개뿐이고, 설정 목록은 `voice_styles` 폴더의 JSON을 읽어 Voice Builder 등으로 만든 스타일도 고를 수 있게 한다. 설정의 **미리 듣기**로 바로 들어 본다. ONNX Runtime DirectML로 GPU를 쓰면 11.7초 음성을 0.19초에 만든다(CPU 1.9초). 첫 GPU 합성은 셰이더 준비로 약 1.6초라 말로 듣기 모드에서는 듣는 동안 미리 한 번 합성한다. DirectML이 실패하면 CPU, 모델이 없거나 합성이 실패하면 WinRT 한국어 음성(`windows`)으로 읽는다. 합성한 WAV(Supertonic 44.1 kHz)는 16 kHz로 다시 샘플링한 뒤 50 ms 프레임마다 스펙트럼을 미리 계산해 재생 위치에 맞춰 넘긴다. 마이크와 대역 배치·FFT 구간(64 ms)·갱신 간격이 같아야 두 이퀄라이저 모양이 같다. 처음에는 원래 샘플레이트로 분석해 bin 간격(43 Hz vs 15.6 Hz)과 저음 대역 위치가 달랐다. `VoiceSpectrumFollower`는 대역별 잡음 바닥(천천히 오르는 최소값)도 빼서 마이크의 방 소음이 기둥을 올리지 않게 한다. Kokoro는 공식 언어 목록에 한국어가 확인되지 않아 제외했고, 원본 Supertonic 저장소는 2026-09 보관 처리됐지만 모델 파일은 Hugging Face에 남아 있다.
- 모션은 `VoiceDotField`(작은 점 990개, 한 번의 OnRender)가 그린다. 점마다 고정 무작위 오프셋과 느린 흔들림이 있어 격자처럼 정렬되지 않고 촘촘한 무리로 움직인다. 쉬는 동안 점은 얇은 가로 띠이고, 내 목소리와 답변 음성은 그 줄이 세로로 퍼지는 이퀄라이저다. 이퀄라이저는 실제 스펙트럼이다: `VoiceSpectrum`이 Hann 창 1024점 FFT를 100 Hz–8 kHz 멜 간격 55개 대역으로 묶고 약 -70…-20 dBFS를 0…1로 바꾼다(+3 dB/옥타브 기울기 보정). 처음엔 80 Hz부터 로그 간격이었는데 180 Hz 아래 대역이 FFT bin(16 kHz에서 15.6 Hz)보다 좁아 여러 대역이 같은 bin을 읽어 가운데 약 20열이 한 막대처럼 움직였다. 그래서 대역마다 앞 대역 다음 bin부터 읽게 하고, `VoiceSpectrumFollower`가 대역마다 천천히 줄어드는 최고값으로 나눠(바닥 0.35, 절대값 35% 혼합) 항상 센 기본 주파수가 가운데를 독차지하지 않게 한다. 가운데가 저음, 양쪽이 고음으로 대칭이다. 마이크는 50 ms 버퍼마다 최근 1024개 샘플을 분석한다. 전사·답변 대기는 Fibonacci 배치 구가 기울어진 축으로 회전하는 모양이다. 점마다 목표 위치로 매 프레임 감쇠 이동해 모양이 바뀔 때 끊기지 않고 모핑된다.
- `VoiceEqualizerWindow`는 포커스를 가져가지 않는 topmost 창이다(`WS_EX_NOACTIVATE`). 음악 표시가 있으면 그 위에 둔다. 아래쪽 토글 버튼으로 답변 방식을 바꾸며 설정 **음성 에이전트** 그룹과 같은 값을 저장한다.
