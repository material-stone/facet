# Windows 통합 오버레이

2026-10-15: 사용자가 사양에 따른 실제 앱 구현을 요청했다. WPF/.NET 10을 선택하며 설치된 Windows Desktop 런타임을 사용한다. 외부 NuGet 패키지와 서버 없이 실행한다. 프로젝트 프레임워크는 이 제품 구현 결정으로 선언하며 bootstrap 도구가 임의 선택한 것이 아니다.

Core는 시간·수면 회차·검증·CSV를 소유한다. Desktop은 UI, 트레이, 전역 단축키, DPAPI 파일 저장을 소유한다. 별도 콘솔 검증은 가상 시간을 주입해 날짜 경계, 절전 복귀, 결측, CSV를 확인한다. 저장 검증과 UI 점검은 독립 데이터 경로를 사용한다.

기본 위치는 LaunchProtocol.DataRoot가 반환하는 기존 LocalAppData 하위 경로다. 제품명 변경 후에도 기록 경로는 유지한다(0056). 전체 JSON을 Windows DPAPI 사용자 범위로 암호화하고 원자적 교체 및 이전 버전 백업을 사용한다. CSV는 사용자가 선택한 위치에 평문으로 내보낸다. 자동 시작은 기본 꺼짐이며 설정에서 사용자가 켠다. 닫기는 트레이로 숨기며 종료는 별도 명령이다.
