# 런처 웹 검색

검색 엔진 선택과 웹 주소 열기는 [0059](0059-launcher-search-engines-and-addresses.md)에서 확장했다. 아래 Google 고정·설정 필드 없음은 최초 구현 시점의 정책이다.

2026-10-25: `? ` 접두사와 검색어를 입력한 뒤 Enter를 누르면 Google 검색 URL을 Windows 기본 HTTPS 브라우저로 연다. 기본 검색 엔진은 브라우저별 내부 설정을 추측하지 않고 Google로 명시한다. 기존 `> help`는 도움말 토글을 유지하고 `?` 한 글자에는 도움말·검색 실행을 연결하지 않는다.

Desktop/QuickLaunchWebSearch가 모드 판별·빈 검색어 검증·고정 HTTPS 주소와 URI query 인코딩·기본 브라우저 연결 조회를 소유한다. 실행은 URL의 UseShellExecute로 위임하고 브라우저 실행 파일이나 입력된 shell 명령을 직접 실행하지 않는다. 검색어는 Enter 전에는 네트워크로 보내거나 저장하지 않는다. 빈 검색어와 실행 실패는 입력을 유지하고 오류를 표시한다. Core·저장 스키마·설정 필드는 변경하지 않는다.

`? ` 입력 시 앱 후보·고스트는 숨기고 HTTPS 연결의 실제 실행 파일에서 기존 QuickLaunchIcons로 아이콘을 조회한다. ASSOCF_IS_PROTOCOL은 현재 사용자 기본 연결을 읽는다. 연결·아이콘 조회는 작업 스레드에서 런처 세션당 한 번 수행하고 검색어 수정 중에도 완료된 아이콘을 유지한다. 이전 세대·숨긴 세션 결과는 화면에 반영하지 않는다. 아이콘을 구하지 못해도 검색은 동작하며 아이콘 공간만 숨긴다. 검색 실행은 아이콘 완료를 기다리지 않는다.

도움말에 `? 검색어`와 Google·기본 브라우저·Enter 실행 안내를 기존 아이콘 스타일로 추가한다. 앱·경로·alias·예약 명령어·Codex 채팅 모드와 배경·포커스·숨김 정책은 보존한다.
