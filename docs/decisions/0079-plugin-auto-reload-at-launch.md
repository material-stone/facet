# 시작 시 켜 둔 플러그인 자동 재승인

2026-11-05: [0073](0073-widget-grid-and-plugins.md)의 "파일이 바뀌면 다시 켤 때까지 불러오지 않는다"를 대체한다. 플러그인을 수정할 때마다 체크가 풀려 다시 켜야 하는 불편을 사용자가 없애 달라고 요청했다.

## 결정

- 앱 시작 때 사용자가 켜 둔 플러그인은 파일이 바뀌었어도 현재 파일을 불러오고, 성공하면 새 SHA-256을 승인값으로 삼는다.
- 새 값은 메모리에서 갱신하고 다음 저장 때 기록한다. 시작 중에는 Controller가 아직 구성되지 않아 `Commit`을 쓸 수 없고, 값을 잃어도 다음 시작에 같은 승인을 반복할 뿐이다.
- 불러오기에 실패하면 이전 승인값을 유지하고 설정에 오류를 표시한다. 체크 표시는 켠 기록을 따르므로 실패해도 풀리지 않는다.
- 끈 플러그인은 지금처럼 코드를 실행하지 않는다. 실행 중에 파일을 바꾼 경우의 즉시 적용은 기존 **다시 불러오기**를 쓴다.

## 대가

해시 고정이 주던 변조 차단이 사라진다. 플러그인 폴더에 쓸 수 있는 프로그램이 켜 둔 플러그인의 DLL을 바꾸면 다음 시작 때 경고 없이 앱 권한으로 실행된다. 폴더는 현재 사용자 소유이고 같은 권한의 프로그램은 저장 데이터에도 접근할 수 있어, 개인 개발 환경에서 편의를 택했다. 해시는 저장 형식 호환을 위해 계속 기록한다.
