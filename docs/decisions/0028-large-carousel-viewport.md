# 큰 중앙 캐러셀과 부분 이웃 표시

현재 관리 화면은 [0032](0032-single-management-screen.md)에 따라 달력 하나만 표시하며 아래 다중 항목 정책은 과거 결정이다.

2026-10-24: 사용자는 중앙 항목 확대, 양쪽 이웃 일부 표시와 순환 이동 경로 숨김을 요청했다. 0017의 세 항목 전체 표시 정책을 대체한다.

OverlayCarousel은 가용 폭 82%와 그림자 여백을 뺀 높이에 맞추되 최대 폭 1280 DIP를 사용한다. 내부 설계 좌표는 1280×800이며 이웃 배율은 86%, 간격은 폭의 1.8%를 18~40 DIP로 제한한다. 선택 항목은 양 축 중앙에 전부 표시하고 이웃은 viewport 가장자리에서 자른다. 대칭 상하 92 DIP 여백으로 탭과 분리한다.

드래그에서 선택 항목과 들어오는 항목만 위치·배율을 보간한다. 나머지 항목은 opacity 0으로 반대편 목적지에 즉시 배치하고 스냅 완료 후 표시한다. 방향 반전·짧은 드래그·저장 거절·중단된 스냅도 마지막 유효 전환만 가시성을 복구한다. 빈 그림자 배경 캐시와 전경 직접 렌더링은 유지한다.

JournalChecks의 --carousel-live-profile은 합성 할 일/노트가 있는 실제 전체 화면 오버레이에 native 마우스 드래그를 입력한다. WPF Rendering 간격과 프레임당 transform 적용, UI CPU·할당·GC·레이아웃·그림자 재생성을 기록한다. PresentMon ETW도 시도하며 이벤트가 없으면 실제 디스플레이 FPS나 GPU 시간으로 환산하지 않는다. 그림자/블러 제외 비교는 진단 실행에만 적용하고 종료 시 복구한다. 화면 픽셀·사용자 기록을 저장하지 않는다.

크기별 중앙 정렬·선택 항목 전체 표시·이웃 일부 표시·순환 경로 숨김과 기존 편집 저장·포커스 동작을 검증한다.
