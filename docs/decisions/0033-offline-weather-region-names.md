# Windows 날씨 좌표의 실제 지역명

2026-10-24: 사용자가 Windows 자동 위치도 `현재 위치` 대신 `서울특별시` 같은 지역명으로 표시하도록 요청했다. 0031의 자동 위치 표시 정책을 확장한다.

Desktop/DashboardWeather/WeatherAdministrativeRegions가 같은 모듈의 한국 17개 시·도 경계 JSON을 검증·로드하고 현재 좌표의 포함 여부를 계산한다. Polygon·MultiPolygon과 내부 구멍을 처리하며 단순히 가까운 도시를 고르지 않는다. 기존 수동 선택의 지역명은 그대로 사용한다.

WindowsWeatherLocation은 유효한 좌표에 해당하는 한국어 시·도 이름을 붙인다. 한국 경계 밖이나 포함 지역을 찾지 못한 좌표는 `현재 위치`를 유지하며 다른 도시를 추측하지 않는다. 위치 정확도는 Windows가 준 좌표와 포함된 경계 자료의 해상도에 의존한다. 날씨 조회 좌표·권한·저장·취소·진행 막대 정책은 변경하지 않는다.

좌표는 앱 내 메모리에서 판별하며 외부 역지오코딩 요청, 추가 API 키·패키지, Core 의존성을 추가하지 않는다. 경계는 geoBoundaries KOR ADM1의 원본 GeoJSON에서 추출하고 한국어 명칭을 현재 시·도 이름으로 정규화한다. 자료 연도·출처·라이선스는 [지역 자료](../design/weather-regions.md)에 유지한다.
