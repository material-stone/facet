# 0006 — 대시보드와 검토형 AI 로드맵

2026-10-17: 수면 추이와 제작 로드맵을 한눈에 보고 입력 항목의 의미를 이해할 수 있도록 요청받았다.

Desktop에 DashboardView와 AgentRoadmapView를 추가한다. 대시보드는 저장된 최근 7/14일 수면과 실제 WorkItem 단계별 작업 수, 실행 계획의 현재 구간을 표시한다. 결측은 0으로 그리지 않고 날짜별 빈칸으로 표시한다. 수면 시간 계산에 필요한 잠들기 지연은 기본 입력으로 옮긴다.

AI 공급자·인증이 정해지지 않았고 건강 정보 외부 전송 금지 규칙이 있으므로 앱은 API를 임의 연결하지 않는다. 사용자가 검토 가능한 제작 정보 요청문을 복사해 자신이 쓰는 AI Agent에 전달하고 JSON 답변을 붙여 넣는다. Core/AgentRoadmap은 형식과 길이·중복을 검증하고 Desktop에서 전체 미리보기 후 명시적으로 반영한다. 새 제안은 제안 단계의 WorkItem으로만 추가하며 SourcePlanKey로 중복을 막고 기존 작업·증거·집중 상태를 보존한다. 수면/설정/치료 정보는 요청문에 포함하지 않는다. 기존 AppData v2와 암호화 저장 경계는 유지한다.

기존 논리 경로(오늘 -1, 수면 0, 제작 1, 설정 2)는 보존한다. 실제 탭 인덱스는 논리 경로에 2를 더한다. 대시보드는 -2, AI 로드맵은 4다. 시작과 트레이 더블클릭은 대시보드로 연결한다.

검증은 결측·자정 경계 수면 계산, AI 형식 오류·중복·기존 작업 보존, 기존 Core 검사와 Release 빌드, 격리 데이터 경로의 WPF 렌더와 입력 흐름으로 수행한다.
