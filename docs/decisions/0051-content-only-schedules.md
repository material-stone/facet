# 이름 없이 내용만 작성한 일정

2026-10-25: 일정의 Name은 내용이 있으면 비어 있을 수 있다. Core/DaySchedule.Validate는 null 이름과 기존 길이/색상/레이블/시간 오류, 이름과 내용이 모두 공백인 저장 항목을 거절하며 이름 또는 내용이 있는 일정을 허용한다. JSON 필드와 schemaVersion은 그대로 유지한다. 이름을 내용으로 만들어 저장하지 않는다.

Desktop/OverlayScheduleEditor의 기존 Esc/바깥 클릭 검증·원자 저장 경로를 그대로 사용한다. 내용만 작성한 새 일정은 빈 이름으로 저장되며 저장 실패 시 초안과 모달을 유지한다. 이름과 내용이 모두 비어 있는 새 일정은 저장 없이 닫힌다. OverlayScheduleDial은 이름이 빈 항목에 내용의 첫 텍스트 줄을 레이블로 사용해 선택·재편집·삭제와 드래그를 유지한다. 선행 빈 줄과 앞뒤 공백을 제외하고 CRLF/LF/CR 줄바꿈에서 첫 줄만 표시하며 이름/내용 기반 레이블을 모두 한 줄로 제한하며 폭이 넘으면 CharacterEllipsis 말줄임표를 표시한다. 표시 문자열은 저장 이름이나 전체 내용에 반영하지 않는다.

말줄임표가 적용된 레이블에만 전체 표시 문자열을 공용 다크 테마 툴팁으로 제공한다. 내용 기반 레이블은 첫 줄만 제공한다. 실제 텍스트 폭과 최종 레이블 폭으로 생략 여부를 계산하며, 레이블 이탈·클릭/드래그·데이터 교체·화면 숨김 시 툴팁을 닫는다. 부채꼴과 짧은 레이블에는 툴팁을 표시하지 않는다.

모든 레이블은 하나의 FrameworkElement에 직접 그리므로 WPF ToolTipService의 소유 요소 기반 재진입 판정에 맡기면 같은 다이얼 안에서 레이블을 다시 호버할 때 열리지 않을 수 있다. 다이얼에서는 기본 ToolTipService를 비활성화하고 레이블 hit 영역 변경 시 재사용 ToolTip.IsOpen을 직접 제어한다. 표시 중인 레이블에 진입하면 대기 없이 열며 레이블 사이 이동에는 새 전체 텍스트와 위치를 적용한다. 화면 밖 검증에서는 팝업을 열지 않는다.
