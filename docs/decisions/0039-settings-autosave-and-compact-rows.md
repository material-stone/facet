# 설정 자동 저장과 촘촘한 행

2026-10-24: 사용자가 설정 변경의 실시간 저장과 행 간격 축소를 요청했다. 0038의 수동 저장 버튼 정책을 대체한다. 저장 형식과 Desktop/Core 경계는 유지한다.

OverlaySettingsView의 체크박스·슬라이더·지역·날짜 선택은 값 변경 시 바로 검증·저장·적용한다. 텍스트는 연속 입력을 모아 300ms 입력 정지 후 자동 저장하며 입력란 포커스 이탈과 화면 이탈에는 대기 중인 저장을 즉시 실행한다. 검색어만 바꾸는 동작은 저장을 시작하지 않는다. 초기 로드와 프로그램 갱신은 자동 저장하지 않는다.

자동 저장 성공 시 컨트롤을 다시 로드하지 않고 저장한 입력의 baseline만 갱신해 커서·선택·IME 조합·슬라이더 드래그·스크롤과 검색을 유지한다. 잘못된 시각·단축키·시간 관계와 저장 실패는 기존 값을 보존하고 편집 초안을 유지한다. 인라인 오류와 실패 때만 보이는 재시도 버튼을 제공한다. 값 수정으로도 재시도하며 Ctrl+S와 기존 오버레이 이탈 저장 경로를 보존한다. 관리 창의 미저장 설정 보호는 유지한다.

일반 저장 버튼을 없애고 하단에 자동 저장 상태를 표시한다. 설정 행 최소 높이는 62에서 44 DIP로, 좌우 콘텐츠의 상하 여백은 12에서 5 DIP로 줄이고 행 사이 2 DIP 여백을 제거한다. 그룹 간격은 28에서 20 DIP로 줄이며 여러 줄 입력과 긴 설명에는 필요한 높이를 허용한다.

검증은 합성 Store와 주입한 시작 등록 콜백으로 수행한다. 즉시 저장·텍스트 연속 입력 병합·미완성 값 거부·실패 후 자동 재시도·커서/컨트롤 보존·검색 무저장과 줄어든 행 간격을 화면 밖에서 확인한다. 실제 사용자 설정과 자동 시작 등록은 검사하지 않는다.
