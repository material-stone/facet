# 받은 M4A의 편집 목록 제거

2026-11-07: YouTube에서 받은 fragmented M4A에 편집 목록(`moov/trak/edts`)이 있으면 저장 전에 그 박스를 `free`로 바꾼다.

- Windows 미디어 엔진(WPF `MediaPlayer`, WinRT `MediaPlayer` 모두)은 이런 파일을 열면 위치를 곡 끝으로 옮겨 오류 없이 소리를 내지 않는다. 앱에는 재생 중으로 보인다.
- 편집 목록은 AAC 인코더 지연(확인한 파일은 1600샘플, 약 36ms)을 건너뛰는 용도다. 제거하면 곡 시작이 그만큼 늦어질 뿐 음원과 길이는 유지된다.
- 박스 이름 4바이트만 바꾸므로 파일 크기와 배치가 그대로이고, 저장된 길이 검사도 통과한다. FFmpeg나 다른 재생 엔진을 추가하지 않는다.
- 이미 받아 둔 파일은 재생을 준비할 때 같은 처리를 하므로 다시 받지 않는다. 음악 폴더의 사용자 파일은 읽기 전용 경계(ADR 0094)에 따라 고치지 않는다.
- 일반(non-fragmented) M4A는 건드리지 않는다.
