# 전체 화면 반투명 오버레이

2026-10-23: 사용자가 단축키로 여는 전체 화면 오버레이와 뒤 화면이 보이는 반투명 배경을 요청했다. 기존 작은 상태창을 같은 Desktop/OverlayWindow 안에서 교체한다.

- 일반 앱 실행·재실행은 관리 창 대신 오버레이를 연다(2026-10-23 시작 화면 변경). `--tray` 자동 시작만 숨긴다. 실행·단축키·트레이 요청은 전경 앱이 있는 모니터 하나의 전체 Bounds를 사용한다. 작업 표시줄을 포함하며 native 픽셀 좌표를 적용해 모니터 배율과 음수 좌표를 보존한다.
- Window 전체 Opacity는 1로 유지하고 Design 토큰의 배경 Brush에만 투명도를 적용한다. 기존 요약·진입 버튼을 사용하며 이번 범위에서 새 대시보드를 만들지 않는다.
- 요청해서 여는 화면이므로 입력 포커스를 받고 Esc를 처리한다. 닫으면 이전 전경 창으로 돌아간다. 기존 전역 Esc 감시와 클릭 통과·작은 창 위치/너비 설정은 사용하지 않는다. 기존 저장 필드는 호환성을 위해 유지한다.
- 기본 Ctrl+Alt+O와 사용자 설정 단축키는 보존하며 Win modifier도 허용한다. 다른 앱과 충돌하는 조합은 기존 등록 실패 경로로 안내한다.
- 전체 화면/야간 자동 숨김은 직접 여는 화면을 차단하지 않는다. 조용한 시간의 업무 내용 숨김과 화면 공유 모드는 유지한다. 전체 화면 앱에서 알림을 생략하는 설정은 유지한다.

Core의 모델·저장 스키마와 Desktop → Core 의존 방향은 유지한다. 합성 데이터와 WPF 창에서 실제 단축키, Esc, 모니터 Bounds, 배경 alpha, 클릭 통과 방지, 포커스 복귀를 검증한다.
