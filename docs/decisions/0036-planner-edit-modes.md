일정 편집의 저장된 색상/레이블 쌍 선택은 제거하고 개별 색상·레이블만 편집한다. 내용 입력은 왼쪽 위 정렬이다. 일정 시간 버튼으로 내부 모달을 열어 하나의 작은 달력(연/월/일)에서 시작일과 종료일을 순서대로 고르고 각 시작/끝 시간을 함께 선택해 확인하면 요약에 반영한다. 취소/Esc는 날짜·시간 선택만 되돌린다. 실제 시작 날짜를 바꾸어도 원본 OwnerDate를 보존해 canonical 항목을 이동하며 30분 단위를 유지하며 기간의24시간 상한은 후속0037에서 제거했다. 저장 형식은 변하지 않는다.

2026-10-25 후속 입력 정책: 뒤로 가기 버튼은 Focusable/IsTabStop을 끄고 클릭과 기존 Esc 동작만 제공한다. 다이얼 입력 시작·하루 화면 열기·모달 종료 시 Tab 정지점이 아닌 DayPage가 키 입력을 받아 Esc 캡처 취소와 모드 스택을 보존한다. Tab 순서는 탭 메뉴→할 일 입력→할 일 항목→기록이며 버튼을 건너뛴다. 일정 수정 창 바깥 클릭은 기존 확인의 검증·원자 저장을 실행한 뒤 모달만 닫으며 클릭과 마우스 해제를 뒤에 전달하지 않는다. 검증/저장 실패 시에는 오류·초안·모달을 유지하며 수정 후 재시도한다. 일정 수정 창의 Esc도 같은 검증·자동 저장을 수행하고 성공 시 최상위 모달만 닫는다. 자동 저장에 맞춰 확인/취소 버튼은 제거하고 기존 일정의 삭제 버튼만 제공한다. 새 일정의 현재 이름/내용이 모두 공백뿐이면 색상·레이블·날짜/시간 변경과 관계없이 Esc/바깥 클릭은 commit 없이 닫는다. 기존 일정과 이름/내용이 있는 새 초안은 검증·자동 저장·실패 보존을 적용하며 내용이 있으면 이름은 비어 있어도 된다. 이름 없는 일정의 표시·저장 경계는0051을 따른다. 날짜·시간 선택 창 바깥 클릭은 그 창만 닫아 최상위 모드 경계를 유지한다.
