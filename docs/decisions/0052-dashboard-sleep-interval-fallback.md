# 0052 — 대시보드 수면량의 기록 구간 대체 표시

2026-10-25: 0050의 대시보드 그래프에서 입면·각성 분이 없어도 잠 시도와 기상이 있으면 값을 표시한다. 두 분 값이 모두 있으면 기존 EstimatedSleepMinutes를 사용하고, 어느 하나라도 미입력일 때는 SleepTracking.TimeSpan의 잠 시도~기상 전체 구간을 사용한다. 이미 입력된 한쪽 분만 빼거나 미입력을 0으로 저장하지 않는다.

Desktop/SleepDurationChart.Minutes는 그래프 표시 값 선택을 한 곳에서 소유하며 점·선·축·수치·툴팁에 같은 값을 사용한다. 그래프 수치는 시간만 표시하고 상단에는 날짜 범위만 둔다. 툴팁과 접근성 이름은 보정된 값과 대체 값 모두 ‘수면 시간’으로 통일하며 대체 값은 민트색 빈 점으로 구분한다. 시각이 부족하면 미확인 줄·선 단절을 유지하고 실제 0시간 추정값은 0축에 유지한다. 두 분이 입력됐지만 잘못된 기존 데이터의 추정 계산이 실패하면 구간으로 대체하지 않는다.

Core의 원자료·null·EstimatedSleepMinutes와 수면 탭 평균은 변경하지 않으며 저장 형식·외부 전송·날짜 클릭·투명 배경을 유지한다. 자정 통과와 동일 시각의 24시간 구간은 기존 투영 규칙을 재사용한다.

검증은 합성 기록의 두 시각만 저장한 직후 표시, 한쪽 분만 입력한 값, 보정된 추정값 우선/실제 0, 자정 통과/24시간, 시각 결측, 값 종류의 접근성·마커, 점 클릭과 원자료 보존, 화면 밖 렌더, 기본 검사와 Release 배포로 수행한다. architecture 명령은 null이며 기존 Desktop→Core 경계를 소스에서 확인한다.
