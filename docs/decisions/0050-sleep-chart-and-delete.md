# 0050 — 수면 삭제·시간대 배경과 대시보드 수면량

2026-10-25: 0049의 대시보드 요약·빠른 입력 카드를 투명한 최근 7일 수면량 꺾은선 그래프로 대체한다. 공유 수정 창에는 저장된 기록에만 삭제 버튼을 제공하고 수면 탭 하단 힌트는 제거한다.

Core/SleepTracking.Delete는 원본 날짜·내용을 대조한 뒤 해당 기록 하나를 RemovedSleep에 복사하고 Sleep에서 제거한다. 원본 충돌은 변경 전에 거절한다. Desktop/SleepRecordEditor는 Controller.Commit으로 삭제하고 저장 실패 시 모달·원본·입력을 유지하며 삭제 버튼으로 다시 시도한다. 삭제 후 대시보드·수면 탭이 함께 갱신되며 미저장 새 양식에는 삭제 버튼을 표시하지 않는다.

Desktop/SleepDurationChart는 기존 SleepTracking.Week와 EstimatedSleepMinutes만 읽어 날짜별 추정 수면량을 표시한다. 계산 가능한 이웃 날짜끼리만 직선으로 연결하며 미기록·계산 정보 부족은 별도의 미확인 줄로 표시하고 0시간 점과 구분한다. 점과 날짜 버튼은 같은 수정 모달로 연결되며 키보드로도 접근할 수 있다. 실제 0시간은 0축 위에 유지한다. 배경·면적 채우기·기존 수면 요약/버튼은 표시하지 않는다. 숨김 상태에는 타이머를 추가하지 않고 기존 대시보드 갱신 경계를 재사용한다.

Settings.SleepGraphTransparencyPercent는 선택적으로 읽히는 0~100 값이며 누락 시 기존 불투명 배경을 보존하는 0이다. 설정의 수면 그룹에서 ‘수면 그래프 배경 투명도’ 슬라이더로 즉시 자동 저장한다. SettingsEditing에서 유한수·범위를 검증한다. OverlaySleepView는 배경 brush alpha만 적용해 시간대 그래프의 선·막대·텍스트·입력은 선명하게 유지하며 대시보드 그래프에는 적용하지 않는다. 변경 저장 실패의 초안·재시도와 최신 설정 필드 병합은 기존 설정 편집 경계를 따른다. schemaVersion 2와 외부 전송 금지를 유지한다.

검증: Core 삭제 원본 대조·삭제 보관·설정 기본값 왕복, 합성 저장의 삭제 실패/재시도·양쪽 그래프 갱신, 꺾은선의 결측 단절/실제 0·날짜 클릭, 투명 배경 픽셀·배경 alpha와 전경 유지, 투명도 설정의 자동 저장/실패/재로드, 다중 크기 화면 밖 렌더, 기본/OverlayUi 검사와 Release 빌드. architecture 명령은 null이므로 저장·dependency·외부 전송 경계를 소스에서 점검한다.
