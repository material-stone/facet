# 위젯 모달과 음악 저장소

2026-11-05: 위젯이 화면 전체를 덮는 모달을 띄울 수 있게 하고, 음악 목록을 그 모달로 옮기며, 내려받은 음원의 정보를 저장한다.

- `WidgetContext.Modal`(`IWidgetModal`)이 계약이다. 위젯이 뷰를 넘기면 앱은 어두운 배경·틀·배치·포커스 순환·탭 전환 차단만 맡고, 내용과 상태는 위젯이 가진다.
- 한 번에 하나만 연다. 중첩은 Esc와 포커스 처리를 복잡하게 하는데 아직 쓰임이 없다.
- 오버레이의 키 처리가 터널링 단계에 있어 내용이 Esc를 먼저 받을 수 없으므로 `ModalOptions.HandleEscape`로 묻는다. `CanClose`가 false면 Esc·바깥 클릭·숨김에도 유지하고, 위젯 제거·플러그인 교체·화면 재생성은 묻지 않고 닫는다. 콜백 예외는 닫는 쪽으로 처리한다. 격리일 뿐 보안 경계는 아니다.
- 음악 목록은 `ListButton`으로 모달에 띄운다. 목록을 떼면서 타일에 남는 내용이 줄어 기본 크기를 3x8에서 3x2로, 최소 높이를 2로 바꿨다. 이미 저장된 배치는 사용자 크기를 유지한다. ADR 0068의 목록 높이 상한 114는 모달의 560으로 대체한다.
- 저장소는 기존 `<data>/MusicCache`를 확장한다. `<id>.m4a`와 `<id>.json`(제목, 바이트 수, 길이, 받은 시각)이 한 곡이며, 길이 없는 이전 파일도 그대로 읽는다. 음원은 크고 기록과 수명이 다르므로 `AppData`나 `IWidgetData`에 넣지 않는다.
- URL을 추가하면 바로 내려받는다. 실패해도 목록에는 남아 행에 표시하고 재생 때 다시 시도한다. 곡을 삭제하면 저장한 음원과 정보도 지운다.
- 음악은 내장 위젯으로 두며 `yt-dlp`는 지금처럼 앱에 포함해 해시를 검증한다. 쿠키·자격 증명·DRM 우회를 쓰지 않는 경계는 ADR 0065 그대로다.
