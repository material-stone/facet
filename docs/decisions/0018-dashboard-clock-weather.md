# 대시보드 날짜·시계와 위치 기반 날씨

2026-10-24 컨디션 추가 이후 첫 행은 시계·날씨·오른쪽 컨디션 사이 동일 가변 간격을 사용한다. 이전 고정 48 간격은 [0040](0040-dashboard-condition-history.md)으로 대체했다.

현재 위치 공급자는 [0031 — Windows 위치와 수동 지역](0031-windows-weather-location.md)으로 교체했다. 아래 ipapi 내용은 최초 승인 당시의 기록이며 현재 앱은 ipapi를 호출하지 않는다.

2026-10-24: 기본 대시보드의 첫 콘텐츠를 날짜·시각과 현재 날씨로 구성한다. 관리 캐러셀·달력·저장 기능은 기존 경계를 유지한다.

2026-10-24 후속 승인: 사용자가 ipapi.co에 공개 IP로 위치를 조회하고 추정 위도·경도를 Open-Meteo에 전달하도록 명시적으로 승인했다. 아래 조회·갱신 정책을 구현한다. imagegen 내장 도구로 생성한 투명 PNG 9종을 현재 날씨에 맞춰 표시한다. 생성 프롬프트와 파일은 [날씨 아이콘](../design/weather-icons.md)에 기록한다.

후속 표시 변경은 [0019](0019-dashboard-reminders-cli-debug.md)를 따른다. 위치는 한국어 지명, 습도는 물방울+퍼센트로 표시하고 날씨 행의 출처·IP 기준 문구를 제거한다. 출처·서비스 조건은 이 문서에 유지한다.

OverlayTabs는 대시보드 영역을 화면 가로 중앙에 최대 800 WPF DIP 너비로 배치한다. 첫 콘텐츠의 위 여백은 탭 메뉴의 상단 여백 + 실제 높이 + 24이며 아래에도 동일한 여백을 둔다. 탭의 높이가 바뀌면 두 여백을 함께 갱신한다. 작은 화면에서는 내용 전체를 균일하게 축소한다. 첫 행은 왼쪽 날짜·요일/오전·오후 시각 그룹과 48 간격 오른쪽 날씨 그룹이다. 날짜와 시각은 각각 한 줄이며 같은 가로 폭에 맞추고 그룹은 왼쪽 정렬한다. 시각 행은 300×60 DIP의 고정 프레임에서 가로·세로 맞춤을 분리해 숫자·오전/오후가 바뀌어도 프레임과 글자 높이 및 아래 콘텐츠 위치가 변하지 않게 한다.

Desktop/OverlayDashboardView는 PC 로컬 날짜를 한국어 연월일·요일과 오전/오후 시:분:초로 표시한다. 화면이 보이는 동안 1초마다 갱신하고 숨김·탭 이동 때 타이머와 진행 중 요청을 중지한다. 날씨는 최초 표시와 10분 주기로 갱신하고 실패 시 5분 뒤 재시도한다. 한 번에 한 요청만 진행하고 취소되거나 이전 표시 세션에서 완료된 응답은 화면에 적용하지 않는다.

2026-10-24 시작 조회 후속 변경: 앱 시작 및 일반 재실행 요청은 날씨 캐시/실패 재시도 대기와 오버레이 표시 설정에 관계없이 즉시 조회한다. 시작 시의 한 요청은 트레이·숨김 상태에서도 완료해 첫 표시 때 사용할 수 있게 하며 앱 종료 시에는 취소한다. 정기 조회는 기존 10분/실패 5분 간격과 숨김 시 취소를 유지한다. 같은 시점의 시작·Loaded·Tick 요청은 하나로 합친다. 조회 중에는 레이아웃 크기에 영향을 주지 않는 진행 막대만 표시하고, 기존 날씨 값과 기준 시각을 그대로 유지한다. 성공·실패·취소·종료 후에는 진행 표시가 남지 않는다.

수동 조회: 날씨 전체 영역을 투명 버튼으로 사용하며 클릭으로 캐시·실패 대기와 관계없이 새로고침한다. 사용자 후속 요청에 따라 날씨 영역은 포커스를 받지 않고 Tab 탐색에서도 제외하며 hover 배경만 표시한다. 조회 중에는 버튼을 비활성화하고 시작·정기·수동 조회 모두 기존 pending 검사로 중복 요청을 방지한다. hover는 별도의 활성 컨테이너에서 처리해 조회 중에도 마우스가 위에 있으면 배경을 유지하고 벗어나면 해제한다. 완료·실패·취소 후에는 다시 사용할 수 있다. 수동 조회는 숨김 시 취소하는 기존 화면 수명을 따른다.

DashboardWeatherClient는 별도 API 키나 패키지 없이 HTTPS로 [ipapi.co](https://ipapi.co/api/)에서 공개 IP에 대응하는 도시·추정 좌표를 구하고, 그 좌표로 [Open-Meteo](https://open-meteo.com/en/docs)의 current temperature_2m, relative_humidity_2m, weather_code, is_day를 조회한다. 위치는 IP 기반으로 추정하므로 VPN·통신사에 따라 실제 위치와 다를 수 있다. 이는 Windows 정밀 위치 권한을 사용하지 않는다. 현재 날씨는 서비스가 제공하는 최신 모델 자료이며 매초 관측치로 표현하지 않고 응답의 기준 시각을 표시하고 출처는 이 문서에 유지한다. 현재 개인용 앱은 Open-Meteo의 [비상업용 무료 API 조건](https://open-meteo.com/en/terms)에 해당한다.

실제 module 이름은 Desktop/DashboardWeather의 WeatherClient다. 같은 폴더의 WeatherIcons만 Icons PNG를 pack URI로 로드하며 작은 해상도로 디코딩하고 Freeze한다. 맑음은 낮/밤을 구분하고 구름 조금·흐림·안개·비·눈·뇌우에 각각 대응한다. 이슬비·어는 비·소나기는 비, 진눈깨비 계열은 눈, 우박 동반 뇌우는 뇌우 아이콘을 재사용한다. 알 수 없는 상태는 아이콘을 숨기고 미확인 문구를 표시하며 다른 날씨로 추측하지 않는다.

요청은 제한된 시간·응답 크기·좌표/수치 검증을 적용한다. 좌표·날씨는 메모리에만 유지하고 IP 문자열·전체 위치 응답은 저장하지 않는다. Core·Store·AI 스냅샷을 읽지 않으며 개인 기록을 전송하지 않는다. 실패 시 기존 날씨와 기준 시각을 유지하고 연결 상태를 표시하며, 처음부터 값이 없으면 --로 표시한다. null을 0으로 바꾸지 않는다.

검증은 합성 HTTP 응답으로 위치/날씨 파싱, 요청 내용, 오류·누락·취소·동시 요청·갱신 간격을 확인한다. 화면 밖 WPF 렌더로 800 너비·작은 화면 축소·실제 탭 아래 배치·대칭 여백·날짜와 시간 폭·날씨 간격을 확인한다. 일반 검사에서는 실제 위치·외부 네트워크·전역 키 입력을 사용하지 않는다.
