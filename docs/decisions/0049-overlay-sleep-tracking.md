# 0049 — 오버레이 수면 빠른 기록과 7일 패턴

2026-10-25: 대시보드의 수면 요약·빠른 입력과 전용 수면 탭의 최근 7일 시간대 그래프를 추가한다. 0048의 오버레이 전용 화면 원칙을 유지하며 수면 DTO만 읽기 전용으로 취급하던 부분을 이 기능에 한해 대체한다. 일반 관리 창·수면 단축키·예약 알림·치료 계획·CSV는 복원하지 않는다.

Core/SleepTracking은 기존 AppData.Sleep/SleepEntry 기상일 키, 부분 기록, 입력 검증, 원본 대조 후 갱신과 날짜별 시간대 투영을 소유한다. 잠 시도와 기상이 같은 시각이면 기존 계산과 같이 24시간 회차로 해석하고, 기상 시각이 앞서면 잠 시도를 전날로 해석한다. 모르는 값은 null이며 추정 실제 수면은 시도·기상·입면 분·각성 분이 모두 있을 때만 표시한다. 편집하지 않는 구형 필드는 복사해 보존한다. 기존 schemaVersion 2와 저장 파일을 그대로 사용한다.

Desktop/SleepTracking은 공유 SleepRecordEditor, 7일 OverlaySleepView와 시간대 표시를 소유한다. 그래프는 오늘을 포함한 기상일 7개를 같은 시간축에 놓으며 미기록·부분 기록·잠 시도~기상 구간을 구분한다. 기본 축은 전날 12시~기상일 18시이며 이 범위 밖 기록은 모든 행에 공통인 축을 확장해 생략하지 않는다. 날짜 또는 행 클릭으로 같은 편집기를 열며 대시보드는 오늘 기록을 연다. 기상일은 편집 중 고정하고 다른 날짜는 그래프에서 선택한다.

편집기는 두 시각을 먼저, 입면·각성 분과 메모를 추가 기록으로 표시한다. 시간 선택은 공통 CalendarTimeInput 스타일을 재사용하고 빈 시각을 지울 수 있다. 저장·Ctrl+S, Esc/바깥 클릭·숨김·종료의 자동 저장은 Controller.Commit과 DPAPI Store를 통하며 검증/저장 실패는 모달·입력·재시도를 유지한다. 취소 버튼은 미저장 초안만 폐기한다. 빈 새 양식은 기록을 만들지 않는다. 모달은 탭과 달력보다 위에서 입력을 소비하고 중첩 시간 드롭다운부터 Esc로 닫는다. 저장 후 대시보드와 그래프가 함께 갱신되고 표시 중 날짜 변경에도 7일 범위를 갱신한다. 건강 기록은 외부 요청에 포함하지 않는다.

검증: Core의 자정·동일 시각·부분/결측·잘못된 입력·충돌·구형 필드 보존 검사, 합성 암호화 저장의 빠른 입력/행 클릭 수정/실패 보존/재시도/Esc, 화면 밖 다중 크기 렌더, 기본 검사와 Release 빌드. architecture 명령은 null이므로 dependency direction과 외부 전송 경계를 소스에서 점검한다.
