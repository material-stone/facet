# Facet 사용 안내

앱·프로젝트·실행 파일 이름은 **Facet**입니다. 화면·트레이·알림·작업 표시줄과 제품 정보에도 적용합니다. 기존 기록·자동 실행을 이어 쓰도록 저장 경로·Run 키·인스턴스 식별자는 유지합니다. 이전 고정 바로가기는 `artifacts/Facet/Facet.Launcher.exe`로 한 번 다시 고정하세요. [이름과 호환 경계](../decisions/0056-teum-project-naming.md).

컨디션은 플러그인입니다. `artifacts/Facet/plugins/condition`을 `<데이터 폴더>/plugins/condition`에 복사하고 설정 → 탭·플러그인에서 켠 뒤 대시보드 편집 모드의 위젯 추가에서 `컨디션`과 `7일 컨디션`을 배치합니다. `컨디션` 위젯은 격자 슬롯을 꽉 채우며, 이 버튼을 누르면 좋음·괜찮음·피곤함·졸림·아픔·스트레스 중 하나를 선택할 수 있습니다. 선택한 시각부터 다음 선택까지 이어지며 암호화 저장됩니다. 아래 **최근 7일 컨디션** 띠는 6일 전 00시부터 오늘 24시까지 보여줍니다. 첫 기록 전과 미래는 투명하며 자정에 하루씩 이동합니다. 구간을 클릭하면 실제 기록 날짜·시각·컨디션을 확인하고 수정하거나 삭제할 수 있습니다. 기록 시각 버튼에서 하나의 날짜·시/분/초 선택창을 열고, 시각과 컨디션은 변경 즉시 저장됩니다. 삭제 버튼은 오른쪽 끝에 있으며 저장·닫기 버튼 없이 Esc나 바깥 클릭으로 닫습니다. 저장 실패 시 변경 내용과 재시도를 유지합니다. 삭제한 변경점의 앞 상태는 다음 기록까지 이어집니다. 아이콘·게이지·선택 목록은 포커스를 받지 않으며 Esc는 열린 팝업부터 닫습니다. [아이콘과 표시 규칙](../design/condition-icons.md).

## 실행과 종료

루트의 `Start-Facet.cmd`를 실행합니다. 이 스크립트는 고정 실행기 `artifacts/Facet/Facet.Launcher.exe`를 엽니다. 이미 실행 중이면 같은 프로세스의 오버레이를 엽니다. 트레이 아이콘 더블클릭도 오버레이를 엽니다. 실행기와 `releases` 폴더, `latest.json`은 함께 보관합니다.

**작업 표시줄에는 `artifacts/Facet/Facet.Launcher.exe`를 고정합니다.** 탐색기에서 이 파일을 우클릭해 **작업 표시줄에 고정**을 선택합니다. 메뉴에 없으면 **더 많은 옵션 표시**에서 확인합니다. 고정 실행기는 `latest.json`에 지정된 최신 버전을 실행하므로 빌드할 때마다 다시 고정할 필요가 없습니다. `releases/<버전>/Facet.exe`나 예전 `Facet-*/Facet.exe`에 고정된 아이콘은 고정을 해제한 뒤 고정 실행기로 다시 고정합니다.

- `Win+Alt+O`: 전체 화면 오버레이 표시/숨김. 설정에서 변경할 수 있으며 기존 저장 조합을 유지합니다.
- `Win+Alt+Space`: 빠른 실행 표시/숨김.
- `Win+Alt+End`: 앱 완전 종료.

빠른 실행과 종료 키는 고정 예약 키입니다. 일반 창을 열던 `Ctrl+Alt+S`·`Ctrl+Alt+P`는 등록하지 않습니다. 트레이 메뉴에는 **오버레이 열기**, **빠른 실행**, 구분선, **종료**만 표시합니다. 트레이 아이콘 더블클릭은 오버레이를 엽니다. 일반 오버레이와 빠른 실행은 포커스를 잃어도 유지됩니다. Esc는 현재 입력 모드에 맞춰 오버레이를 숨기며 단축키 토글과 빠른 실행 내부의 바깥 클릭 닫기는 유지합니다. 정상 종료와 버전 전환은 편집 저장에 성공해야 진행하며 실패하면 초안과 실행 중 앱을 유지합니다.

설정의 **앱 시작**에서 직접 실행 시 오버레이 표시와 Windows 로그인 시 자동 실행을 따로 조절합니다. 로그인 자동 실행은 `--autostart --tray`로 창을 열지 않습니다. 직접 실행 시 표시를 끄면 짧은 실행 안내 토스트만 표시합니다. 기존 `--tray` 시작도 숨김을 유지합니다.

이미 켜진 로그인 자동 실행이 구버전 실행 파일을 가리키면 앱 시작 때 고정 실행기로 보정합니다. 자동 실행을 꺼 둔 선택은 유지합니다. 고정 실행기가 없으면 자동 실행을 새로 켤 수 없으므로 실행기와 `releases`, `latest.json`을 함께 보관합니다.

## 수면량과 7일 패턴

수면 위젯과 기록 창, 에이전트 수면 도구는 **수면 플러그인**이 제공합니다. `artifacts/Facet/plugins/sleep` 폴더를 `<데이터 폴더>/plugins/sleep`에 복사하고 **설정 → 탭·플러그인**에서 켭니다. 기록은 플러그인을 켜지 않아도 앱 시작 때 `plugin-data/facet.sleep.dat`로 옮겨지고 원본은 `backups`에 남습니다([ADR 0083](../decisions/0083-sleep-plugin-and-store.md)).

대시보드는 기존 수면 요약 대신 **최근 7일 수면량** 꺾은선 그래프를 표시합니다. 각 점이나 아래 날짜를 누르면 그 기상일의 기록을 수정하며 미기록 날짜도 새 입력창을 열 수 있습니다. 입면 분·각성 분이 모두 있으면 두 시각에서 이를 뺀 시간을, 둘 중 하나라도 비어 있으면 **잠 시도~기상 전체 구간**을 표시합니다. 수치는 시간만 표시하고 툴팁의 명칭은 모두 **수면 시간**으로 통일하며 대체 값은 민트색 빈 점으로 구분합니다. 한쪽 분만 입력했을 때도 전체 구간을 표시하고 미입력을 0으로 저장하지 않습니다. 두 시각이 부족한 날짜는 하단 **미확인** 줄에 표시하고 선을 끊습니다. 실제 0시간은 0시간 축에 표시합니다. 그래프 배경은 항상 투명합니다.

대시보드 그래프 아래에는 **평균 수면 시간**만 표시하고 ‘몇 일 기준’ 문구는 표시하지 않습니다. 최근 7일의 표시 가능한 수면 시간만 평균에 포함하고 실제 0분은 포함하며 시각이 부족한 기록은 제외합니다. 값이 없으면 —로 표시하고, 수면 탭과 같은 분 단위 반올림·시간 형식을 사용합니다.

수면 탭의 **오늘 수면 기록** 또는 대시보드의 오늘 날짜/점을 눌러 입력합니다. 잠자려 한 시각과 최종 기상 시각을 선택하고 저장합니다. 시각의 **비움**은 미확인 값으로 돌리며, 추가 기록을 펼치면 잠드는 데 걸린 분·밤중에 깨어 있던 분·메모를 입력할 수 있습니다. 모르는 값은 비워 두고 실제로 없었던 각성만 0으로 적습니다.

**수면** 탭은 오늘을 포함한 최근 7일을 기상일별 한 줄로 보여줍니다. 민트 막대는 잠 시도~기상 구간이며 실제 수면 시간과 다릅니다. 자정 전 잠 시도는 전날 시각으로 이어지고, 시간축의 ‘전’은 기상일 전날을 뜻합니다. 기본 범위는 전날 12시~기상일 18시이며 다른 시간대 기록이 있으면 전체 행의 공통 축을 확장합니다. 날짜별 수면 시간과 평균은 대시보드와 같은 기준을 사용합니다. 입면·각성 분이 모두 있으면 추정 수면을, 어느 하나라도 비어 있으면 잠 시도~기상 전체 시간을 표시하고 평균에 포함합니다. 두 시각이 부족한 기록은 정보 부족으로 표시하고 평균에서 제외하며, 실제 0분은 포함합니다. 평균 옆의 ‘몇 일 기준’ 문구는 표시하지 않으며, 시간 표시에서 0인 단위는 생략합니다.

날짜나 그래프 행을 누르면 해당 기상일의 동일 기록을 수정합니다. 기상일은 입력창에서 고정하며 다른 날짜는 그래프에서 선택합니다. **저장**·`Ctrl+S` 또는 `Esc`·바깥 클릭·오버레이 숨김·종료 시 저장을 시도합니다. 저장/검증 실패 시 창과 입력을 유지하며 **다시 시도**할 수 있습니다. **취소**는 저장하지 않은 입력만 폐기합니다. 빈 새 양식은 기록을 만들지 않습니다. 기존 수면 기록의 추가 필드는 보존하며 외부로 전송하지 않습니다.

저장된 기록의 수정 창 왼쪽 아래 **기록 삭제**를 누르면 해당 날짜의 기록을 삭제합니다. 실패하면 기록과 입력창을 유지하며 **삭제 다시 시도**를 누를 수 있습니다. 삭제 성공 후 두 그래프를 함께 갱신합니다. 아직 저장하지 않은 새 기록에는 삭제 버튼이 없습니다.

**설정 → 플러그인 → 수면 → 수면 패턴 배경 투명도**에서 수면 패턴 위젯의 배경을 조절합니다. 0%는 불투명, 100%는 투명이며 변경 즉시 저장됩니다. 기본값은 기존 배경을 유지하는 0%입니다. 글자·막대·선의 진하기는 유지하며 대시보드 꺾은선 그래프에는 영향을 주지 않습니다. 수면 탭 최하단의 힌트 문구는 제거했습니다.

## 설정

오버레이의 가장 오른쪽 **설정** 탭에서 설정을 바꿀 수 있습니다. 탭에 진입하면 검색 입력란에 자동으로 포커스가 갑니다. 상단 검색 입력에 키워드를 적으면 이름·설명·현재 값에 일치하는 설정만 실시간으로 표시하고 일치하는 부분을 강조합니다. 여러 키워드는 공백으로 구분하며 모두 일치하는 행을 찾습니다. 검색을 지워도 작성 중인 값은 유지됩니다. 설정 이름에 마우스를 올리면 설명을 볼 수 있고, 긴 목록은 스크롤합니다. 체크·슬라이더·지역 선택은 변경 즉시 자동 저장·적용하며, 텍스트는 입력을 멈춘 뒤 0.3초 후 저장합니다. 포커스 이탈과 오버레이 닫기에도 대기 중인 변경을 저장하며 `Ctrl+S`로 바로 시도할 수 있습니다. 저장 오류가 있으면 초안을 유지하고 안내와 **다시 시도** 버튼을 표시합니다. 잘못된 입력은 수정하면 다시 자동 저장됩니다.

## 사용자 알림

[로컬 CLI](../workflows/reminder-cli.md)로 등록한 사용자 알림을 유지합니다. 설정의 **사용자 알림 사용**, **전체 화면에서는 알림 숨김**, **화면 공유 모드**가 적용됩니다. 알림은 저장 성공 후 전달 처리되며 재시작 후 같은 알림을 다시 표시하지 않습니다. 토스트의 열기 버튼은 오버레이로 연결됩니다. 앱이 꺼져 있으면 알림을 전달할 수 없습니다.

기존 수면 기록 알림·카페인·저녁 준비 예약 알림과 일반 창의 알림 이력 화면은 제거했습니다. 수면 입력은 대시보드와 수면 탭에서 직접 엽니다.

## 전체 화면 오버레이

### 에이전트로 Facet 기능 쓰기 (MCP)

에이전트는 `artifacts/Facet/Facet.Mcp.exe`(MCP 서버)를 통해 일정·알림 등록, 날씨, 컨디션·수면 기록과 조회를 합니다. 도구 목록과 범위는 [ADR 0069](../decisions/0069-agent-tools-and-conversation-archive.md)에 있습니다. 앱이 꺼져 있으면 첫 호출 때 트레이로 시작합니다. 한 번 등록하면 새 배포 후에도 같은 경로를 씁니다.

```powershell
codex mcp add facet -- "<저장소 경로>\artifacts\Facet\Facet.Mcp.exe"
claude mcp add facet --scope user -- "<저장소 경로>\artifacts\Facet\Facet.Mcp.exe"
```

Codex 등록 후에는 Codex 앱을 다시 시작해야 도구가 보입니다. Claude CLI에서는 `claude`를 실행한 뒤 "오늘 일정 알려줘"처럼 요청하면 됩니다. 컨디션·수면 도구를 쓰면 그 기록이 해당 모델 제공자로 전송됩니다.

### 빠른 실행

설정 → **단축키·빠른 실행 → 검색 엔진**에서 **Google·네이버·Bing**을 선택합니다. 변경은 자동 저장되며 런처에 이미 입력한 검색어에도 다음 Enter부터 바로 적용됩니다. 이전 설정의 기본값은 Google입니다. `? 검색어`를 입력하고 Enter를 누르면 선택한 엔진의 검색을 Windows 기본 브라우저에서 엽니다. `? `만 입력해도 왼쪽에 기본 브라우저 아이콘을 표시하며 검색어를 수정하는 동안 유지합니다. 검색어가 비어 있으면 실행하지 않습니다. 아이콘을 찾지 못해도 검색은 사용할 수 있습니다. 입력 중에는 검색어를 전송하거나 검색 후보를 요청하지 않습니다.

`? example.com/path`처럼 웹 주소를 입력하면 HTTPS를 보충해 해당 페이지를 바로 엽니다. `? https://example.com/path?q=one#part`는 검색하지 않고 경로·query·fragment를 유지해 엽니다. `http://localhost:8080`, IP 주소도 사용할 수 있습니다. 완전한 `https://…` 또는 `http://…` 주소는 `?` 없이 입력해도 열립니다. 공백이 포함된 일반 문구는 검색어로 처리합니다.

빈 입력란에는 예시 문구를 표시하지 않습니다. `> `를 입력하면 후보 목록에 예약 명령어가 표시되며 현재 `help`를 지원합니다. `> h`처럼 입력하면 고스트를 추천하고 Tab으로 `> help`를 완성합니다. Enter 또는 후보 클릭으로 실행하면 입력창 위에 **기본 입력 / @ 경로 / @@ alias** 도움말이 열리고 입력은 비워집니다. `> help`를 다시 실행하면 닫힙니다. 다른 검색 중에도 도움말은 유지되며 `?`는 도움말을 열지 않습니다. 작은 화면에서는 도움말 위에서 휠로 스크롤하고, 입력란이 비었을 때 방향키·PageUp/PageDown도 사용할 수 있습니다.

`Win+Alt+Space`로 Windows 주 모니터 중앙에 입력창과 후보 목록만 띄웁니다. 뒤 화면에는 블러나 반투명 배경을 적용하지 않고 화면 캡처도 하지 않습니다. 입력란은 후보 개수와 무관하게 중앙에 유지됩니다. 입력 중 기존 아이콘을 유지하고 새 대상의 아이콘 조회가 완료되면 교체합니다. `Esc` 또는 같은 단축키로 숨깁니다. 입력창·후보 목록 밖을 클릭하면 함께 숨겨집니다. 다른 앱으로 포커스를 옮겨도 입력창과 작성 중인 입력을 유지합니다. `Win+Alt+O`는 일반 오버레이로 전환하며 저장된 배경 효과를 다시 적용합니다.

- `notepad`: PATH/PATHEXT에서 앱을 검색합니다. 정확히 일치하는 이름, 접두사, 포함 순으로 최대 8개를 표시하며 중복 명령은 PATH/PATHEXT 순서의 파일을 사용합니다. 앱 인자 입력은 지원하지 않습니다.
- `@D:\project`: 절대 경로의 파일·폴더와 바로 아래 경로 후보를 표시합니다. 폴더는 탐색기로 열고 파일은 탐색기에서 선택합니다.
- `@@작업`: 설정 → 오버레이·단축키 → **탐색기 alias**에 등록한 이름을 추천합니다. 한 줄에 `작업=D:\project`처럼 입력하고 저장합니다. 경로에 공백이 있어도 따옴표 없이 등록할 수 있습니다.

입력 중 가장 가까운 후보를 흐린 글자로 완성합니다. 마우스를 움직여 후보 위에 올리거나 위/아래 방향키로 이동하면 해당 행이 선택되고 후보 텍스트·아이콘이 입력란에 반영됩니다. 입력란의 포커스를 유지하고 커서를 끝에 두어 바로 입력하거나 지울 수 있습니다. 탐색 중에는 원래 목록을 유지하며 이후 입력·삭제는 채워진 텍스트에서 이어서 수정하고 다시 검색합니다. 같은 후보 안에서 마우스를 움직여도 수정 중인 텍스트·커서·선택 영역은 유지하며, 다른 후보로 옮겼을 때만 입력란을 다시 채웁니다. 정지한 마우스는 키보드 선택을 바꾸지 않습니다. `Tab` 또는 입력 끝의 오른쪽 화살표로도 완성하며 `Enter`나 목록 클릭으로 실행합니다. 가져올 수 있는 아이콘은 입력란과 후보 텍스트 왼쪽에 표시하고 없으면 텍스트만 표시합니다. 후보가 없으면 목록은 숨겨집니다. 실행 실패 시 입력을 유지하고 이유를 표시합니다. alias는 기존 기록과 함께 암호화 저장됩니다.

### 대시보드·일정·수면·설정

전역 단축키를 누르면 Windows 주 모니터를 작업 표시줄까지 덮습니다. 처음에는 투명하고 선명한 배경으로 표시한 뒤 설정한 표시 시간(기본 280ms)에 걸쳐 반투명 배경과 블러가 함께 짙어집니다. 상단 중앙에는 둥근 직사각형의 플로팅 탭 메뉴, 화면 중앙에는 선택한 탭의 콘텐츠가 표시됩니다. HUD도 같은 진행률로 나타나고 사라집니다.

탭은 **대시보드 → 일정 → 수면 → 채팅 → 설정** 순서이며 처음에는 날짜와 시각이 있는 대시보드 화면을 엽니다. 탭 버튼은 바깥 프레임과 간격 없이 이어지며 가장 왼쪽과 오른쪽 모서리만 둥글게 표시합니다. `Ctrl+[`와 `Ctrl+]`는 탭 목록을 좌우로 순환합니다. 달력은 현재 PC 로컬 날짜의 월을 `0000년 0월` 제목, 수평 구분선, 일~토 요일과 7열 날짜 격자로 표시합니다. 일요일은 빨강, 토요일은 파랑이고 오늘은 조금 밝은 배경, 선택한 날짜는 테두리로 강조합니다. 오늘을 선택하면 배경과 테두리가 함께 표시됩니다. 날짜에 마우스를 올리면 배경이 은은하게 밝아지며 벗어나면 원래 배경으로 돌아갑니다. 오늘 날짜는 호버 중에도 배경 강조를 유지하고 선택 테두리는 그대로 표시합니다. 일정 탭의 달력 항목에서 Page Up/Down은 월 이동, 오늘 버튼과 Home은 오늘을 선택하고 해당 월로 돌아갑니다. 달력에는 툴팁을 표시하지 않습니다.

대시보드는 최대 폭 800의 영역을 가로 중앙에 배치하며, 탭의 상단 위치 + 실제 높이 + 24만큼 위아래에 같은 여백을 둡니다. 첫 콘텐츠는 왼쪽 날짜·요일과 그 아래 오전/오후 시각이며, 두 줄은 같은 가로 폭에 맞춥니다. 시각 줄은 높이 60 DIP로 고정해 초·오전/오후가 바뀌어도 영역과 글자 높이가 달라지지 않습니다. 오른쪽에는 날씨·기온·습도 표시 영역을 둡니다. 앱 시작·일반 재실행 시 날씨를 즉시 조회하며, 조회 중에는 기준 시각 문구와 같은 줄의 오른쪽 끝에 진행 막대만 표시하며 기존 기준 시각을 그대로 유지합니다. 날씨 영역을 클릭하면 즉시 수동 새로고침합니다. 날씨 영역과 진행 막대는 포커스를 받지 않으며 Tab 탐색 대상에서도 제외합니다. 조회 중에는 새로고침 버튼을 비활성화해 중복 요청을 막으며, 마우스가 날씨 영역 위에 있으면 배경 호버는 유지합니다. 갱신 중에는 기존 값과 자료 기준 시각을 유지합니다. 현재 날짜·시각은 초마다, 이후 날씨는 10분마다 갱신합니다. Windows 위치 서비스로 좌표를 받아 현재 날씨를 조회하며 ipapi는 호출하지 않습니다. 설정의 「날씨 위치」에서 「위치 접근 허용」으로 Windows 권한을 허용하고 「Windows 자동 위치」를 사용할 수 있습니다. 권한이 없거나 위치를 얻지 못하면 같은 목록에서 한국 시·도/시·군·구를 직접 선택하고 설정을 저장하세요. 직접 선택한 지역은 대표 좌표로 조회하며 설정 저장 즉시 갱신합니다. 자동 위치는 한국 17개 시·도 경계와 좌표를 대조해 「서울특별시」 같은 실제 지역명을 표시합니다. 판별할 수 없는 좌표는 「현재 위치」를 유지하고, 직접 선택한 지역은 선택한 한국어 지명으로 표시합니다. Windows 위치 정확도는 GPS·Wi-Fi 등 장치 환경에 따라 달라집니다. 현재 좌표는 저장하지 않고 선택한 지역 ID만 기존 암호화 저장소에 보관합니다. 맑음·구름·안개·비·눈·뇌우와 낮/밤을 귀여운 투명 아이콘 9종으로 구분하고, 기온·물방울 아이콘+습도 퍼센트·자료 기준 시각을 함께 표시합니다. 앱 시작 조회는 화면이 숨겨져 있어도 완료하며, 이후 정기 조회는 대시보드를 숨기면 중지합니다. 앱 종료 시에는 모든 조회를 취소합니다. 실패하면 이전 값과 기준 시각을 유지하고 5분 뒤 재시도하며, 아직 값이 없으면 --로 표시합니다.

시간·날씨 아래에는 오늘 주요 일정·알림 카드를 가로로 나열합니다. 항목이 많으면 가로로 스크롤할 수 있습니다. 일정과 알림은 [알림 CLI](../workflows/reminder-cli.md)로 추가·조회·완료·취소할 수 있으며, 앱이 실행/트레이 중일 때 시각을 확인해 알림을 표시합니다. 오버레이에서 F8을 누르면 영역 디버그 모드를 켜고 끕니다. 켜진 동안 요소 위에 마우스를 올리면 테두리와 이름·크기를 볼 수 있습니다.

일정 탭에는 중앙 달력 화면 하나만 있습니다. 양쪽 빈 캐러셀 항목과 좌우 드래그 전환은 제거했습니다. 달력의 큰 크기·중앙 배치와 그림자·블러는 유지하며 작은 화면에서는 내용을 함께 축소합니다. 날짜를 누르면 기존 하루 일정·할 일·기록 화면을 열고 Esc 또는 돌아가기 버튼으로 달력에 복귀합니다. 배경은 열 때 읽은 블러 스냅샷을 표시 중 계속 유지합니다. [이전 캐러셀 성능 기록](carousel-performance.md)은 세 항목 구성 당시의 측정입니다.

일정 탭의 달력과 하루 일정 관리는 **달력·일정 위젯** 하나이며 위젯 편집에서 옮기거나 크기를 바꿀 수 있습니다. 일정·할 일·기록은 데이터 폴더의 `calendar.dat`에 날짜별로 저장합니다. 첫 실행 때 이전 `records.dat`를 `backups/`에 백업한 뒤 복사합니다. 관리 첫 항목은 **중앙 달력만** 표시합니다. 날짜를 클릭하거나 Enter/Space를 누르면 달력이 왼쪽으로 페이드 아웃되고 하루 관리 화면이 오른쪽에서 페이드 인됩니다. 하루 화면에서 **Esc** 또는 **뒤로 가기**를 누르면 입력을 저장하고 반대로 전환합니다. 기록 편집 중 첫 Esc는 저장 후 기록 보기로만 돌아가며 다음 Esc가 달력으로 돌아갑니다. 일정 수정 창에서 Esc를 누르면 변경 내용을 저장한 뒤 그 창만 닫으며, 날짜·시간 선택 중에는 현재 선택값을 유지한 채 선택 창만 먼저 닫습니다. 저장 실패 시 수정 창과 초안을 유지합니다. 달력에서 Esc를 누르면 오버레이를 닫습니다. 달력 방향키는 하루/일주일 단위로 선택을 옮기고, Enter/Space로 하루 화면을 엽니다. 월/오늘 단축키는 달력 화면에서만 동작합니다.

하루 화면의 상단에는 왼쪽 꺾쇠 **뒤로 가기** 버튼과 연월일/요일이 한 줄에 표시되고, 왼쪽에는 **24시간 파이 일정**, 오른쪽에는 날짜를 중복하지 않는 **할 일과 기록**이 있습니다. 원의 위는 0시/24시, 아래는 12시이며 시계 방향으로 흐릅니다. 다이얼과 뒤로 가기 버튼은 Tab 또는 마우스 포커스를 받지 않습니다. 뒤로 가기는 클릭 또는 Esc로 실행하며 Tab은 탭 메뉴에서 할 일 입력으로 이동합니다. 일정 수정 창에서 Esc를 누르거나 바깥을 클릭하면 변경 내용을 자동 저장한 뒤 닫고 현재 일정 관리 화면을 유지합니다. 새 일정의 이름과 내용이 모두 비어 있으면 색상·레이블·날짜/시간을 바꿨어도 Esc/바깥 클릭으로 저장 없이 창만 닫습니다. 공백만 입력한 경우도 빈 값으로 처리합니다. 이름 없이 내용만 작성해도 Esc/바깥 클릭으로 자동 저장하며 다이어그램에는 내용의 첫 줄을 레이블로 표시합니다(선행 빈 줄과 앞뒤 공백은 제외). 이름과 내용 기반 레이블은 모두 한 줄로 표시하고 길면 말줄임표로 줄입니다. 생략된 레이블에 마우스를 올리면 전체 레이블 텍스트가 다크 테마 툴팁으로 표시됩니다. 다시 열면 이름은 빈 상태로 유지하고 내용을 편집할 수 있습니다. 잘못된 입력이나 저장 실패 시에는 오류와 입력 내용을 유지하며 수정 창을 열어 둡니다. 날짜·시간 선택 창이 열려 있으면 바깥 클릭은 가장 위의 선택 창만 닫습니다. 호를 따라 양방향으로 드래그하면 시간을 채우며 같은 칸 안에서도 8 DIP 이상 움직이면 30분이 선택됩니다. 놓으면 이름·날짜/시간·색상·레이블·내용을 입력하는 모달이 열립니다. 날짜·시간 버튼을 누르면 작은 달력 하나와 그 아래 시작/끝 시간 선택이 한 창에 표시됩니다. 달력에서 시작일을 고르면 종료일 선택으로 넘어가며 시작일 이전 날짜는 비활성화됩니다. 위의 시작/끝 날짜 버튼으로 선택 대상을 다시 바꿀 수 있습니다. 같은 날의 종료 시간은 시작 시각보다30분 이상 뒤인 항목만 활성화하고 이후 날짜에는 전체 시간대를 선택할 수 있습니다. 종료 날짜에24시간 상한은 없습니다. 시작 날짜/시간을 바꾸면 종료값을 유효한 범위로 맞춥니다. 연도·월 이동은 날짜 확정과 분리하며 날짜·시간 선택 창은 버튼 아래의 독립 레이어에서 내용에 맞는 높이로 표시하며 일정 수정 창의 크기를 바꾸지 않습니다. 선택 즉시 두 끝점을 일정 초안과 버튼에 반영하고 별도 확인/취소 버튼이나 하단 시작→끝 요약은 표시하지 않습니다. Esc/바깥 클릭은 현재 값을 유지한 채 선택 창만 닫으며, 일정 수정 창에는 확인/취소 버튼이 없으며 Esc/바깥 클릭으로 저장하고 닫습니다. 끝은 시작 이후여야 하며30분 단위를 사용합니다. 내용은 입력란 왼쪽 위부터 작성합니다. 색상 코드 칸을 클릭하거나 포커스 상태에서 Enter/Space를 누르면 색상 선택 창이 열립니다. 색상 영역과 색조 막대 또는 #RRGGBB 코드 입력으로 선택하면 즉시 초안에 반영됩니다. 기존 색상 프리셋도 그대로 사용할 수 있으며 Esc나 바깥 클릭은 선택한 색을 유지하면서 색상 선택 창만 닫습니다. 자정을 넘는 일정은 실제 시작 날짜에 한 번만 저장합니다. 반시계로00시를 지나면 전날에서 시작하며, 드래그 중에는 선택한 날짜 부분을 불투명하게, 전날/다음 날 부분을 반투명하게 표시합니다. 저장 후에는 현재 보고 있는 날짜와 겹치는 부분만 표시합니다. 예를 들어 전날23시~당일1시는 당일 화면에서00시~01시만 보이고, 전날 화면에는23시~24시가 보입니다. 여러 날 일정의 중간 날짜는00시~24시 전체가 표시됩니다. 부채꼴/이름으로 수정하면 잘린 구간 대신 원래 시작 날짜와 전체 시간을 편집하며 삭제도 같은 원본 일정에 적용됩니다. 모달의 시작 날짜와 날짜가 포함된 시작/종료 안내로 경계를 확인할 수 있습니다. 일정 편집 창은 기존 가로 폭의2/3 크기로 중앙에 표시하며 메모 아래에는 기존 일정의 삭제 버튼만 표시하며 새 일정에는 빈 버튼 영역을 남기지 않습니다. 반투명 배경은 상단 탭과 바깥 여백을 포함한 화면 전체를 덮고 뒤쪽 조작을 막으며, 모달을 열 때마다 설정 탭의 배경색을 같은 RGB의 반투명 색조로 적용합니다. 하루 화면에서는 캐러셀 드래그를 잠급니다.

다이어그램의 일정 부채꼴이나 이름 레이블을 클릭하면 해당 일정의 수정 모달이 열리며 **확인**으로 저장하거나 삭제할 수 있습니다. 일정 몸통을 드래그하면 길이를 유지한 채 시작/끝 시각이 함께 이동합니다. 실제 시작/끝 시각의 변을 드래그하면 해당 경계만30분 단위로 조절하며 양방향으로00시를 넘길 수 있습니다. 드래그 중 이전/다음 날짜 부분은 반투명하고 현재 표시 날짜는 원래 색이며, 놓으면 자동 저장한 뒤 해당 날짜의 구간만 표시합니다. Esc로 드래그를 취소할 수 있고 저장 실패 시 바꾼 시간을 편집 모달에 유지합니다. 날짜에 의해 잘린00/24시 변은 원래 시작/끝 경계로 바꾸지 않습니다.00시에 시작과 끝이 겹치는24시간 일정은 그 변의 안쪽에서 시작, 바깥쪽에서 끝을 잡습니다. 호와 변이 만나는 모서리는 둥글게 표시합니다. 저장된 일정 부채꼴은 불투명하며 최대 반경의 90% 안에 표시합니다. 겹치는 일정은 짧은 쪽을 더 작은 반경으로 위에 그려 둘 다 선택할 수 있습니다. 바깥 10% 링은 새 일정 드래그에 사용할 수 있고, 전체30분 방사형 격자는 표시하지 않습니다. 생성 가능한 빈 영역이나 바깥 링에 마우스를 올리면 시작할30분 칸 하나의 흐린 테두리만 표시하며 드래그 중에는 숨깁니다. 이름 레이블과 저장된 부채꼴 어느 쪽에 마우스를 올려도 해당 일정의 테두리만 조금 밝아지며 면이 살짝 위로 들리고 작은 그림자가 생깁니다. 부채꼴 채움색과 레이블 배경은 유지합니다. 레이블과 연결선 위치는 움직이지 않고 레이블 테두리만 조금 밝아지며 손 모양 커서로 클릭 가능함을 표시합니다. 일정 이름은 다이어그램 양쪽의 가까운 빈 공간에서 색상 테두리의 둥근 사각 상자로 표시합니다. 다른 이름·시계·범례를 피하고 연결점은 중앙각에 고정하지 않으며 굵은 선으로 원 바깥을 우회해 연결합니다. 공간에 들어가지 않는 이름은 초과 개수로 표시하며 부채꼴을 클릭해 수정할 수 있습니다. 아래 범례는 색상·레이블 쌍으로 묶습니다. 일정 편집의 저장된 쌍 선택 목록은 없으며 색상 견본/직접 입력과 독립 레이블 입력으로 설정합니다. 범례는 스크롤할 수 있습니다. 별도의 일정 추가 버튼이나 일정 선택 목록 없이 다이어그램에서 생성·선택합니다. 빈 다이어그램에는 「원 안을 드래그하여 일정 추가」 안내만 원 중앙에 표시하고 일정을 만드는 드래그 중에는 이 안내를 숨깁니다. 중앙 점/원과 「하루를 그려보세요」 제목은 표시하지 않습니다. 왼쪽 아래 범례는 실제 색상/레이블 항목만 표시하고 제목이나 빈 목록 안내는 표시하지 않습니다. 현재 시각은 원 중앙에서 바깥 테두리로 이어지는 노란 바와 어두운 바탕선으로 표시합니다. 위는00시, 오른쪽06시, 아래12시, 왼쪽18시이며 분·초에 따라1초마다 회전합니다. 바는 일정/호버/드래그/레이블보다 위에 표시하고 마우스 입력은 기존 다이얼로 전달합니다. 표시 날짜와 관계없이 현재 로컬 시각을 보여주며 숨김·탭 이동 중에는 갱신을 멈추고 다시 열면 즉시 시각을 맞춥니다.

하루 화면의 할 일·기록 패널은 좌우·상하 바깥 여백을 동일하게 유지합니다. 기록 상자는 남은 높이를 채우고 보기/편집 모드에서 같은 크기를 사용하며 긴 기록은 상자 안에서 스크롤합니다. 할 일 목록은 별도로 스크롤하고 저장 상태는 기록 제목 옆에 표시하며 시작 안내 문구는 「자동 저장 중」입니다. 하루 화면은 달력과 별도의 넓은 영역을 사용해 오른쪽 패널 옆으로 다이어그램과 레이블 공간을 확보합니다.

할 일 항목은 입력란과 같은 가로 폭을 사용하고 스크롤바가 생기면 두 폭을 함께 맞춥니다. 할 일은 Enter 또는 입력란 포커스 이탈로 추가하며 클릭·Space/Enter로 완료 전환, Del로 삭제합니다. 기록은 Markdown 보기에서 클릭/Enter로 편집하며 원문을 저장합니다. 할 일과 기록은 입력 정지 후 자동 저장하고 날짜/화면 이동·숨김·정상 종료 전에도 저장합니다. 저장 실패 시 초안과 모달을 유지하고 달력 복귀를 막습니다. 기존 할 일·기록과 일정은 같은 날짜별 암호화 저장을 사용합니다. Tab/Shift+Tab으로 탭, 달력 또는 하루 화면의 조작 요소, 할 일, 기록을 순환합니다. 모달 안에서는 포커스가 모달 내부를 순환합니다. 작은 화면에서는 전체 배치를 축소하고 기록/범례/모달 본문에 공통 스크롤바를 사용합니다. 목록과 선택 목록은 실제 스크롤바가 있는 축에만 막대 공간을 확보합니다. 글자는 효과 bitmap에 넣지 않고 직접 그립니다.

일반 오버레이와 빠른 실행 입력창은 현재 포커스된 화면과 관계없이 **Windows 주 모니터**에만 표시합니다. 오버레이가 입력 포커스를 받아 **Esc** 또는 같은 전역 단축키로 닫습니다. 다른 앱으로 포커스를 옮기면 편집 내용을 저장한 뒤 같은 페이드로 숨기며 새로 선택한 앱의 포커스를 유지합니다. 저장 실패 시 입력과 표시 요청을 유지합니다. 오버레이 안에서 입력란 사이를 이동하거나 일반 오버레이의 배경을 클릭해도 닫히지 않습니다. 설정한 숨김 시간(기본 280ms)에 걸쳐 선명하고 투명해진 뒤 창이 숨겨집니다. Esc나 단축키로 닫으면 이전 앱으로 돌아갑니다. 전환 중 다시 단축키를 누르면 현재 진하기와 흐림 정도에서 반대 방향으로 이어집니다. 뒤쪽 앱을 클릭하지 않도록 클릭 통과는 사용하지 않으며, 이전 작은 상태창의 위치·너비 설정도 적용하지 않습니다. 알림 팝업은 기존처럼 포커스를 가져가지 않습니다.

오버레이 **설정 → 오버레이 모양**에서 값을 조절하면 자동 저장됩니다. `Ctrl+S`로 즉시 저장할 수도 있습니다. 재실행 후에도 유지됩니다.

- **투명도**: 0%는 완전 불투명, 100%는 완전 투명. 글자·탭·입력창은 그대로 유지합니다. 이전 버전의 배경 진하기는 보이는 모습이 유지되도록 변환합니다.
- **배경색**: 색상 팔레트의 견본을 누르면 선택한 RGB 색상으로 배경이 바뀝니다. 투명도와 별도로 저장됩니다.
- **블러 강도**: 0–40, 기본 18. 0은 블러와 배경 캡처를 끕니다.
- **나타나는 시간 / 사라지는 시간**: 각각 0–2000ms, 기본 280ms. 값이 작을수록 빠르며 0ms는 즉시 전환합니다.

블러 강도가 0이면 배경을 캡처하지 않고 단순 반투명으로 표시하므로 뒤 화면의 움직임이 그대로 보입니다. 투명도 100%에서는 블러도 적용하지 않습니다. Windows의 전역 투명 효과 설정은 바꾸지 않습니다.

오버레이 자체도 화면 캡처·공유에 포함됩니다. Discord에서 다른 앱의 창만 공유하면 오버레이가 포함되지 않으므로 오버레이가 있는 전체 화면을 공유하세요. 블러용 뒤 화면은 오버레이를 열기 직전에 별도 작업 스레드에서 긴 변 최대 1280px의 한 프레임으로 읽고, 표시 중에는 고정합니다. 다시 열면 새 배경을 읽습니다. 숨기면 화면에서 즉시 분리하고, 진행 중인 캡처가 끝나는 대로 버퍼와 GDI 자원을 해제합니다. 배경 화면을 파일에 저장하거나 Agent로 전달하지 않습니다.

Windows 캡처 도구의 편집 창이나 영역 선택 화면이 보이는 동안에는 오버레이의 **항상 위** 표시를 잠시 해제합니다. 캡처 도구를 닫거나 최소화하면 포커스를 가져오지 않고 복구합니다. 앱이 백그라운드에서 실행 중이기만 한 경우에는 해제하지 않습니다. 일반 오버레이와 빠른 실행 입력창 모두 캡처 도구로 포커스가 이동할 때는 유지합니다.

오버레이 달력의 날짜를 직접 선택하면 사용자가 작성한 할 일과 노트가 표시됩니다. 화면 공유용 모드는 팝업의 개인 내용을 일반 문구로 바꿉니다. **오버레이 화면 자체는 숨기지 않으므로** 화면 공유 전 오버레이를 닫아 주세요.

## 저장과 호환성

설정·달력·일정·수면·사용자 알림은 기존 DPAPI 암호화 저장과 원자적 교체·자동 백업을 사용합니다. 일반 창에서 사용하던 작업·실천 계획·프로젝트 일지·구형 설정도 저장 파일에 보존하지만 일반 창의 편집·실행 기능은 제공하지 않습니다. 수동 백업/복원·CSV 화면은 제거했습니다. 실제 사용자 저장소는 검사에 사용하지 않습니다. 컨디션은 `plugin-data/facet.condition.dat`에 같은 방식으로 저장합니다.

## 개발 및 검증

`scripts/build.ps1`은 기본적으로 화면을 띄우지 않는 배포 실패 보존·Core·오버레이 통합 검사를 실행하고 `artifacts/Facet/releases/<version>-<build>/`에 프레임워크 의존 배포본을 생성합니다. 앱과 고정 실행기 배포가 모두 성공한 뒤에만 `artifacts/Facet/latest.json`을 원자적으로 교체합니다. 성공 후 이전 배포본과 staging·이전 manifest를 자동 삭제해 최신 release만 남깁니다. 실행 중이거나 잠긴 이전 release는 다음 성공 빌드에서 다시 정리하며 앱을 강제 종료하지 않습니다. 실패한 빌드의 새 출력은 제거하고 기존 배포본을 유지합니다. 같은 버전을 반복 빌드해도 새 폴더는 고유합니다. 추가 검사는 `scripts/check.ps1 -OverlayUi`(화면 밖 달력·탭), `-Launcher`(실행기·시작 화면), `-OverlayVisuals`(격자·빨간 배경을 포함한 블러·입력)로 필요한 경우만 선택합니다. build.ps1에도 같은 옵션을 사용할 수 있습니다. [변경 범위별 검증](../workflows/testing.md)을 참고하세요. 다른 PC에서는 Windows 10 2004 이상과 .NET 10 Windows Desktop Runtime이 필요합니다.

테스트용 실행: `Facet.exe --data-dir <별도 폴더>`. 개발 검증용 `--storage-check`는 반드시 빈 데이터 폴더에서 사용합니다. `--diagnostics`는 QA용 런타임 속성과 상태창 렌더를 해당 데이터 폴더에 남기므로 실제 건강 데이터를 사용하는 일반 실행에는 넣지 마세요.
